## 1. Deliverable in one sentence

The pure, emulator-independent ripping engine: object-safe `RipPlugin` /
`Depacker` / `Deprotect` traits, a `Registry` that scans detectors in parallel
(`rayon`, fully synchronous), tries depackers and **recursively rescans**
depacked buffers with bounded depth and `via` provenance, `Finding` handles
stored server-side so `extract(finding_id, as=raw|prg)` can materialize bytes
to disk later — shipped with **zero real plugins** (only `NoopDeprotect`
registered) and proven end-to-end by fixture plugins in `tests/`.

### 5.1 `src/ripper/mod.rs` — kinds + the two core traits

```rust
//! Plugin-based ripping engine (ADR-2). Pure over `MemImage`: no emulator,
//! no async — CPU-bound scanning stays synchronous and parallelizes with
//! rayon. Extension contract: add a format = one plugin file + one line in
//! `registry::default_registry()`.

pub mod deprotect;
pub mod extract;
pub mod finding;
pub mod registry;

pub use deprotect::{Deprotect, NoopDeprotect, ProtectionInfo};
pub use extract::{extract, ExtractFormat, Extracted};
pub use finding::{Finding, FindingId};
pub use registry::{default_registry, PluginRole, PluginSummary, Registry};

use crate::types::{MemImage, PluginId};

/// What category of artifact a plugin looks for. `Sprite` is reserved
/// (post-P7 backlog); `Boot` arrives with real plugins in P7; `Raw` is the
/// bucket for kind-less reports (e.g. protection detections, ADR-6).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum RipKind {
    Picture,
    Music,
    Sprite,
    Packer,
    Boot,
    Raw,
}

/// A detector. Scans a memory image, returns zero or more findings.
/// Object-safe, registered as `Box<dyn RipPlugin>` (ADR-2): dispatch cost is
/// negligible next to the scan itself, which monomorphizes internally.
pub trait RipPlugin: Send + Sync {
    /// Stable id, e.g. "degas-pi1". Also the `Finding.plugin` value.
    fn id(&self) -> PluginId;
    fn kind(&self) -> RipKind;
    /// One-line description shown by `list_ripper_plugins`.
    fn describe(&self) -> &'static str;
    /// Pure scan. Construct findings with `Finding::new` — the engine
    /// attaches source-buffer and provenance afterwards (§5.2/§5.4).
    fn scan(&self, mem: &MemImage) -> Vec<Finding>;
}

/// A transformer. If `data` is packed by this scheme, return unpacked bytes;
/// the engine re-runs all detectors over the result (bounded depth, §5.4).
/// `None` means "not mine / corrupt" — never an error, never a panic.
pub trait Depacker: Send + Sync {
    fn id(&self) -> PluginId;
    fn describe(&self) -> &'static str;
    fn try_unpack(&self, data: &[u8]) -> Option<Vec<u8>>;
}

// Object-safety is contractual (ADR-2): this must keep compiling.
const _: fn(&dyn RipPlugin, &dyn Depacker, &dyn Deprotect) = |_, _, _| {};
```

No serde/schemars derives on `RipKind` or any engine type — the wire uses
strings, mapped at the tool boundary (§6.3), same rule as `Addr` in P1.

### 5.3 `src/ripper/deprotect.rs` — the seam, dummy only (ADR-6)

use crate::error::{Error, Result};
use crate::types::{Offset, PluginId};

/// What a deprotector recognized. `name` is the protection scheme

pub struct ProtectionInfo {

    pub offset: Offset,

### 5.4 `src/ripper/registry.rs` — engine + THE single registration point

```rust
use std::sync::Arc;

use rayon::prelude::*;

use crate::types::{Addr, MemImage, PluginId};

use super::deprotect::{Deprotect, NoopDeprotect};
use super::finding::Finding;
use super::{Depacker, RipKind, RipPlugin};

/// Depack-bomb guard: a depacked buffer larger than this is skipped with a
/// tracing::warn (ADR-2 consequence). 4× the biggest ST RAM, generous for
/// any legitimate unpack.
pub const MAX_UNPACKED: usize = 16 << 20;

/// Default recursion depth for depack→rescan (levels of unpacking).
pub const DEPTH_DEFAULT: u8 = 2;

pub struct Registry {
    detectors: Vec<Box<dyn RipPlugin>>,
    depackers: Vec<Box<dyn Depacker>>,
    deprotectors: Vec<Box<dyn Deprotect>>,
}

/// Discovery row for `list_ripper_plugins` (progressive disclosure, ADR-5).
#[derive(Debug, Clone, Copy)]
pub struct PluginSummary {
    pub id: PluginId,
    pub role: PluginRole,
    pub kind: Option<RipKind>,     // Some for detectors only
    pub describe: &'static str,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum PluginRole { Detector, Depacker, Deprotect }

impl Registry {
    /// Empty registry — tests build custom ones from fixture plugins.
    pub fn new() -> Self;

    // Builder-style registration (consume + return self; used by
    // default_registry and by tests — this IS the "one registry line"):
    pub fn with_detector(self, p: Box<dyn RipPlugin>) -> Self;
    pub fn with_depacker(self, d: Box<dyn Depacker>) -> Self;
    pub fn with_deprotect(self, d: Box<dyn Deprotect>) -> Self;

    /// All registered plugins, in listing order: detectors, then depackers,
    /// then deprotectors, each in registration order.
    pub fn summaries(&self) -> Vec<PluginSummary>;

    /// Every plugin id (all three roles) — used by the tool layer to
    /// validate a `plugin` filter argument.
    pub fn plugin_ids(&self) -> Vec<PluginId>;

    /// THE scan (algorithm below). `kind = None` scans everything.
    /// `depth` = remaining depack levels; 0 = detectors only.
    pub fn scan(&self, mem: Arc<MemImage>, kind: Option<RipKind>, depth: u8)
        -> Vec<Finding>;
    // impl: self.scan_buffer(mem, kind, depth, &[])

    fn scan_buffer(&self, buf: Arc<MemImage>, kind: Option<RipKind>,
                   depth: u8, via: &[PluginId]) -> Vec<Finding>;
}

impl Default for Registry { /* impl: Self::new() */ }

/// THE single registration point (ADR-2 invariant: add a format = one plugin
/// file + one line HERE). P3 ships the engine only — the sole registrant is
/// the deprotect dummy. P4 adds `with_detector(Box::new(Degas))` lines etc.;
/// a phase that needs to edit anything else in this module is an
/// architecture bug — stop and flag it.
pub fn default_registry() -> Registry {
    Registry::new().with_deprotect(Box::new(NoopDeprotect))
}
```

**`scan_buffer` algorithm — exact, in order (fits 30 lines by delegating
steps B–D to small private helpers):**

- **A. Detectors, parallel.**
  `let mut out: Vec<Finding> = self.detectors.par_iter()
      .filter(|p| kind.is_none_or(|k| p.kind() == k))
      .flat_map_iter(|p| p.scan(&buf))
      .collect();`
  `rayon`'s ordered collect keeps registration order — finding order (hence
  `FindingId` indices) is deterministic for a given buffer + registry.
- **B. Deprotect reporting (only when `kind.is_none()`** — a kind-filtered
  scan asked for that kind; protection reports would be noise). Sequential:
  for each `dp in &self.deprotectors`, if `dp.detect(buf.bytes())` returns
  `Some(info)`, push
  `Finding::new(dp.id(), RipKind::Raw, info.offset, info.len,
  format!("protection detected: {}", info.name))`.
  **`strip` is never called by the engine** — there is no code path to it
  (test §7.2 `strip_is_never_called`).
- **C. Attach.** `out.retain_mut(|f| { let ok = f.attach(&buf, via);
  if !ok { tracing::warn!(plugin = %f.plugin, "dropping out-of-bounds finding"); }
  ok });`
- **D. Depack recursion (runs regardless of the kind filter** — depacking
  serves any kind search). If `depth > 0`, sequentially for each
  `d in &self.depackers`: if `d.try_unpack(buf.bytes())` returns
  `Some(bytes)`:
  - if `bytes.len() > MAX_UNPACKED` or `bytes.is_empty()`: `tracing::warn!`
    and skip (depack bomb / degenerate output);
  - else build `child = Arc::new(MemImage::new(bytes, Addr::new(0)))`,
    `child_via = [via, &[d.id()]].concat()`, and
    `out.extend(self.scan_buffer(child, kind, depth - 1, &child_via))`.
- **E.** Return `out`.

Ordering guarantee (documented on `scan`): per buffer — detectors in
registration order, then deprotect reports, then depack-recursion findings
depth-first in depacker registration order. Deterministic for identical
input; this is what makes `FindingId` indices stable enough to hand out.

### 5.5 `src/ripper/extract.rs` — materialize to disk (never bytes on the wire)

```rust
use std::path::{Path, PathBuf};

use crate::error::{Error, Result};

use super::finding::Finding;

/// Output container formats. `Png` arrives in P4 (needs the planar decoder);
/// the tool layer rejects "png" with invalid_params until then — do NOT add
/// a variant early.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ExtractFormat { Raw, Prg }

impl ExtractFormat {
    pub const fn ext(self) -> &'static str;      // impl: Raw → "bin", Prg → "prg"
    pub const fn as_str(self) -> &'static str;   // impl: "raw" / "prg"
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Extracted {
    pub path: PathBuf,
    pub size: u64,
}

/// Write one finding's bytes to `out_dir` (created on demand), return the
/// path + size — never the bytes (ADR-5: filesystem as intermediate state).
/// Filename: "rip-{seq:04}-{plugin}-{offset:06x}.{ext}"
/// (e.g. "rip-0001-toy-pic-001234.bin"). Synchronous std::fs — the tool
/// layer wraps the call in spawn_blocking (§6.2); the engine stays sync.
pub fn extract(finding: &Finding, format: ExtractFormat, out_dir: &Path,
               seq: u64) -> Result<Extracted>;
// impl: let bytes = finding.bytes().ok_or_else(|| Error::Ripper {
//           plugin: finding.plugin,
//           message: "finding has no attached source buffer".to_string() })?;
//       let payload: std::borrow::Cow<[u8]> = match format {
//           ExtractFormat::Raw => Cow::Borrowed(bytes),
//           ExtractFormat::Prg => Cow::Owned(prg_wrap(bytes)),
//       };
//       std::fs::create_dir_all(out_dir)?;                    // Error::Io via #[from]
//       let path = out_dir.join(format!("rip-{seq:04}-{}-{:06x}.{}",
//           finding.plugin, finding.offset.raw(), format.ext()));
//       std::fs::write(&path, &payload)?;
//       Ok(Extracted { path, size: payload.len() as u64 })

/// Wrap raw bytes in a minimal GEMDOS .PRG so TOS can load/run the rip —
/// the Ultimate Ripper save-as-PRG trick. Layout reference:
/// refs/orionfuzion/r1pp3r/src/R1PP3R.S (the $1c-byte header with text
/// length at +2, data length at +6, and fixup-table handling around its
/// `.exe` label) — cited for the layout ONLY, do not port any code.
///
/// Exact output = 28-byte header + payload (as TEXT) + 4-byte empty fixup
/// table, all big-endian:
///   +0  u16  0x601A          (PRG magic / bra.s)
///   +2  u32  payload.len()   (text segment length)
///   +6  u32  0               (data length)
///   +10 u32  0               (bss length)
///   +14 u32  0               (symbol table length)
///   +18 u32  0               (reserved)
///   +22 u32  0               (program flags)
///   +26 u16  0               (ABSFLAG)
///   +28      payload
///   last u32 0               (empty relocation/fixup table — the TOS
///                             loader reads the first fixup longword even
///                             with ABSFLAG conventions in play; 0 = none)
pub fn prg_wrap(payload: &[u8]) -> Vec<u8>;
// impl: Vec::with_capacity(32 + payload.len()); extend_from_slice the
//       big-endian fields via u16/u32::to_be_bytes; no byte-twiddling.
```

`payload.len()` in a `MemImage` is ≤ `MAX_UNPACKED` (16 MiB) so the
`as u32` in the text-length field cannot truncate; still, guard it:
`payload.len() > u32::MAX as usize` → `Error::Ripper { plugin: …,
message: "payload too large for PRG header" }` (unreachable in practice,
cheap to keep honest — put the check in `extract` before calling `prg_wrap`
so `prg_wrap` stays infallible; findings that large cannot exist).

### 6.2 `src/tools/rip.rs` — the three tools

All three use `#[tool_router(router = rip_router, vis = "pub(crate)")]` on

every registered ripper plugin (parallel, server-side — the agent sees only \
compact findings: id, plugin, kind, offset, size, label, depack provenance). \
Packed regions are unpacked and rescanned up to `depth` levels. Findings \
stay in server memory: pass a finding id to `extract`. Default 32 findings \

1. Validate/normalize args: `kind = a.kind.map(kind_from_str).transpose()?`
   (`Err(msg)` → `invalid_params`); `depth = a.depth.unwrap_or(DEPTH_DEFAULT)
   .min(DEPTH_MAX)`; `limit = a.limit.unwrap_or(RIP_DEFAULT_LIMIT)
   .min(RIP_MAX_LIMIT)`; `offset = a.offset.unwrap_or(0)`. If
   `a.plugin = Some(p)`: reject with `invalid_params(format!("unknown plugin
   '{p}' — see list_ripper_plugins"))` unless `p` matches one of
   `self.registry.plugin_ids()` (compare via `PluginId::as_str`).
2. **Paging path:** if `a.scan_id == Some(n)`: lock `last_scan`; if the
   stored scan's `scan_id == n`, build the page from the stored findings
   (step 5) — no session needed, no re-scan, and `kind`/`plugin`/`depth`
   args are ignored (the stored list already reflects the original scan's
   filters; document this in the arg doc-comments). If it does not match →
   `invalid_params(format!("stale scan_id {n}: latest scan is {latest}; \
   re-run rip"))` (or "no scan in memory: run rip first" when the store is
   `None`).
3. **Fresh scan path:** lock the session mutex; `guard.process_mut()`
   `.ok_or_else(|| wrong_state(guard.state_name(), "running or paused"))?`;
   `let mem = crate::session::memory::acquire(proc).await.map_err(to_mcp)?;`
   capture `out_dir = proc.config().work_dir.join("ripped")`; drop the guard.
4. `let scan_id = self.scan_seq.fetch_add(1, Ordering::Relaxed) + 1;`
   (first scan is 1). Run the CPU-bound scan off the reactor:
   `let reg = Arc::clone(&self.registry); let mem = Arc::new(mem);`
   `let mut findings = tokio::task::spawn_blocking(move ||
   reg.scan(mem, kind, depth)).await.map_err(|e|
   McpError::internal_error(format!("scan task failed: {e}"), None))?;`
   Post-filter: if `a.plugin = Some(p)`, `findings.retain(|f|
   f.plugin.as_str() == p)`. Store:
   `*self.last_scan.lock() = Some(ScanStore { scan_id, findings, out_dir })`
   (lock poisoning: `unwrap_or_else(PoisonError::into_inner)` — pinned; the
   data is replaced wholesale so a poisoned lock holds nothing worth
   protecting. `// verify` clippy is happy; if not, `.expect` is forbidden —
   keep the into_inner form).
5. Page (`page_findings` helper in rip_wire.rs): `total = findings.len()`,
   slice `[offset .. min(offset+limit, total)]`, map each to `FindingOut`
   with `id = FindingId::new(scan_id, absolute_index).to_string()`,
   `has_more = offset + page.len() < total`.

`extract` procedure:

1. `let id = FindingId::parse(&a.finding_id)` → `Error::Parse` maps to
   `invalid_params` with the error's Display string.
2. `let format = format_from_str(a.r#as.as_deref().unwrap_or("raw"))?`
   (§6.3; "png" → `invalid_params("as=png arrives in P4 (graphics decode); \
   use raw or prg")`, anything else unknown → `invalid_params(format!(
   "unknown extract format '{s}': use raw or prg"))`).
3. Lock `last_scan` (brief, no await): `resolve_finding(&guard, id)` (§6.3)
   → `Err(msg)` maps to `invalid_params(msg)`; on success clone the
   `Finding` (cheap: `Arc` + small strings) and the store's `out_dir`; drop
   the lock. Note: extraction works even after the session stopped — the
   buffers live in the store (ADR-10).
4. `let seq = self.extract_seq.fetch_add(1, Ordering::Relaxed) + 1;`
   `tokio::task::spawn_blocking(move ||
   crate::ripper::extract(&finding, format, &out_dir, seq)).await`
   — `JoinError` → `internal_error`; inner `Err(e)` → `to_mcp(e)`.
5. `Ok(Json(ExtractOutput { finding_id: id.to_string(),
   format: format.as_str().to_string(),
   path: extracted.path.display().to_string(), size: extracted.size }))`.

## 12. ADR-10 — append to `decisions.md` (verbatim; fill only the date)

```markdown
## 2026-07-XX — ADR-10: Finding handles resolve against Arc'd source buffers in a single last-scan store

**Status:** accepted
**Context:** ADR-5 requires `extract(finding_id)` to work on a *later* call
than the `rip` that produced the finding — including findings located inside
depacked buffers, which have no bus address and no bytes in the live RAM
image. Something must retain the bytes between calls.
**Decision:** Each `Finding` privately holds an `Arc<MemImage>` of the exact
buffer it was found in (the root snapshot or a depacked child), attached by
the engine during `Registry::scan` (which therefore takes `Arc<MemImage>`).
The tool layer retains exactly ONE `ScanStore { scan_id, findings, out_dir }`
— the latest scan — behind a std (non-tokio) mutex; `FindingId` is
`"<scan>:<index>"`, so ids from any earlier scan are detectably stale and
are rejected with an explicit "re-run rip" error, never silently remapped.
Extraction slices the stored buffer — no depack replay, no emulator access —
so it also works after the session stopped.
**Alternatives considered:** (a) Replaying the depack chain (`via`) at
extract time — cheaper memory, but re-does the work, and couples extract
correctness to depacker determinism; (b) writing every depacked buffer to
disk at scan time — pays I/O on every scan for artifacts that are mostly
never extracted; (c) a multi-scan history — unbounded memory for no v1 use
case.
**Consequences:** Scan buffers stay in memory until the next scan replaces
them (bounded: root ≤ 4 MiB + depacked children ≤ 16 MiB each, depth ≤ 4);
the agent contract is "extract soon after rip, or re-rip"; `Registry::scan`'s
signature refines the ARCHITECTURE.md sketch from `&MemImage` to
`Arc<MemImage>` (synced in the same phase).
```
