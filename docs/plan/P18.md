## 1. Deliverable in one sentence

The static 68000 estimate (P2's `analyze/cycles/`, today contention-BLIND)
gains an STE Shifter/CPU bus-contention model pinned from the proven
`STEIsNotDead/tools/cycles/ste_model.py`: each instruction's cost is split
into **bus (memory-access) cycles** and **internal cycles**, only the bus
share is scaled by a **display-region factor** (`visible` ×3/2, `vblank` ×1,
`mixed` ×413/313), and the `profile` tool reports **blind + contended** side
by side (the measured Hatari path stays the untouched ground truth).

## 3. The pinned model (facts, sources, and the one design decision)

### 3.1 Source facts (do not re-derive)

From `STEIsNotDead/tools/cycles/ste_model.py` (the proven Python model) and
`reference/cycle_counter_plan.md` §Phase-6 in the bundled `m68000-cycles`
skill (which quotes STEIsNotDead's `docs/LEARNINGS.md`):

| Fact | Value | Source line |
|---|---|---|
| VBlank scanlines | **113** — CPU has full bus, **~8 cyc/word** | ste_model.py docstring |
| Visible scanlines | **200** — Shifter steals slots, **~12 cyc/word** | ste_model.py docstring |
| Raw per-word ratio | **12/8 = 1.5×** | ste_model.py line "Contention factor: roughly 50% overhead (12/8 = 1.5x)" |
| Python's applied factors | total × 1.0 (VBLANK) / **1.45** (VISIBLE, "conservative, actual is 40-50%") / 1.25 (MIXED) / VISIBLE for UNKNOWN | `CONTENTION_*` consts + `apply_contention` |
| Frame geometry | 313 scanlines × 512 cycles = 160256 (already `VBL_CYCLES`/`SCANLINE_CYCLES` in `cycles/mod.rs`) | ste_model.py `format_*`, matches P2 |

### 3.2 The design decision (this is the ADR, §9)

`ste_model.py` scales the **total** cycle count by 1.45. We instead scale only
the **memory-access (bus) share** of each instruction by the raw **3/2**
per-word ratio, leaving internal cycles unscaled. Rationale, pinned:

- The Shifter steals **bus slots**; internal cycles (mul/div/shift counts,
  condition-code work) proceed regardless. A `muls` (70 cycles, ~66 internal)
  does not get 45% slower during display — the flat model adds ~31 phantom
  cycles per `muls`.
- The two models agree where it matters: 68000 timing is bus-dominated, and
  **1.45-on-total is exactly 1.5-on-bus diluted by a typical ~10% internal
  share** (0.10 + 1.5×0.90 = 1.45). For fully-bus code (e.g.
  `move.w (a0)+,(a1)+` loops) ours gives the physical 1.5 = 12/8; for
  register-heavy code ours is strictly more accurate.
- `mixed` is the scanline-weighted average of the two bus factors over the
  313-line frame: (200·(3/2) + 113·1)/313 = **413/313 ≈ 1.32** on bus cycles.
  (ste_model.py's hand-rounded 1.25-on-total is superseded by this derivation;
  both are within the model's honesty band.)
- Default region = **`visible`**: worst case, same policy as ste_model.py's
  `UNKNOWN → VISIBLE`, and demo hot loops run during active display — that is
  when fitting the budget matters. Callers who know better say `vblank`.

Presentation decision: **blind + contended, both always returned** (a range,
not a single adjusted number). The blind value keeps its exact current
semantics as the lower bound; the measured Hatari path is untouched ground
truth. The per-instruction `cycles_est` in `disasm` stays blind — contention
is a statistical model over a mix, and a per-insn "contended 6" would be
false precision (§10 out-of-scope).

### 3.3 How memory-access cycles are counted (pinned)

Per instruction, with `total_r = round_st(insn_cycles(bytes))`:

```
bus = min( 4 × word_count  +  data_access_cycles(bytes),  total_r )
```

- `word_count = bytes.len() / 2` — exact, Capstone hands us the instruction
  bytes. Every opcode and extension word is fetched over the bus at 4 cycles
  each; this term also covers EA extension-word fetches (so `ea_cost` is NOT
  reused here — it would double-count them).
- `data_access_cycles` = operand data reads/writes only, **4 per word-or-byte
  access, 8 per long access** (`acc(long)`), classified per §5.2's table.
- The `min` clamp is a safety net (bus ≤ rounded total by construction for
  every covered opcode — the decomposition is exact for bus-bound
  instructions, e.g. `move.l (a0)+,d0` = fetch 4 + read 8 = 12 = table 12);
  also `debug_assert!` the un-clamped value ≤ `total_r` in tests, not in
  release code.
- **Fallbacks, pinned:** `insn_cycles(bytes) == None` (unknown insn, costed 4)
  → `bus = 4` (fully bus). `insn_cycles` Some but `data_access_cycles` None
  (classifier gap) → `bus = total_r` (fully contended — degrades to exactly
  ste_model.py's flat behavior, never *under*-estimates contention).

## 4. Prefetch caveat (comment it, don't model it)

Taken branches/`rts`/`jsr` refill the 2-word prefetch queue at the target;
our fetch term counts only the instruction's own words, so their bus share is
undercounted by ≤8 cycles (`rts`: bus 12 of 16 — the missing 4 are target
prefetch). This is inside the model's honesty band (the ±10% band
`cycle_counter_plan.md` claims for the whole approach) and must be stated in
`contention_bus.rs`'s module doc. Do NOT add prefetch modelling.

## 5. Analyze layer

### 5.1 `src/analyze/cycles/contention.rs` — NEW

```rust
//! STE Shifter/CPU bus-contention model (P18). Pinned from STEIsNotDead's
//! tools/cycles/ste_model.py via the m68000-cycles skill: during visible
//! scanlines the Shifter steals bus slots (~12 cyc/word vs ~8 in VBlank),
//! so MEMORY-ACCESS cycles scale ×3/2 while internal cycles never do —
//! the refinement over ste_model.py's flat ×1.45-on-total (which is this
//! same 1.5 diluted by a typical ~10% internal-cycle share). The result is
//! a *better estimate*, not truth: Hatari's profiler (debug/profile.rs)
//! stays the measured ground truth.

use super::CycleEstimate;

/// Where the code runs relative to the display (ste_model.py
/// ExecutionContext, minus UNKNOWN — the wire default plays that role).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Region {
    /// Active display: Shifter contention (worst case, the default).
    Visible,
    /// Vertical blank: CPU owns the bus.
    Vblank,
    /// Runs across the whole frame: scanline-weighted average.
    Mixed,
}

/// PAL 50 Hz frame split (ste_model.py docstring). Their sum is the
/// 313-line frame already pinned by VBL_CYCLES / SCANLINE_CYCLES.
pub const VISIBLE_LINES: u32 = 200;
pub const VBLANK_LINES: u32 = 113;

/// Bus-cycle scale factor as (numerator, denominator).
/// Visible = 12/8 cyc/word (ste_model.py "12/8 = 1.5x").
/// Mixed   = (VISIBLE_LINES·3 + VBLANK_LINES·2) / (313·2) = 826/626 = 413/313.
const fn factor(region: Region) -> (u64, u64) {
    match region {
        Region::Visible => (3, 2),
        Region::Vblank => (1, 1),
        Region::Mixed => (413, 313),
    }
}

/// Apply the contention model to a range estimate: internal cycles pass
/// through, bus cycles scale by the region factor (truncating integer
/// division, like ste_model.py's int(); bus is a multiple of 4, so the
/// visible 3/2 case is exact). Invariant used: est.bus_cycles <= est.cycles
/// (guaranteed by estimate()'s clamp).
pub fn contended_cycles(est: &CycleEstimate, region: Region) -> u64 {
    let (n, d) = factor(region);
    est.cycles - est.bus_cycles + est.bus_cycles * n / d
}
```

### 5.2 `src/analyze/cycles/contention_bus.rs` + `contention_bus_misc.rs` — NEW

`contention_bus.rs` owns the entry points and nibbles 1–3/6/7/8/9/B/C/D/E;
`contention_bus_misc.rs` owns 0x0/0x4/0x5 (`pub(super)` fns), mirroring the
existing `decode.rs`/`decode_misc.rs` split one-for-one so the two dispatches
stay reviewable side by side. Both import `super::{ea_fields, ea_mode,
word_at, EaMode}` — the same `pub(crate)` primitives `decode*.rs` uses. They
must NOT call `ea_cost` (double-counts extension fetches, §3.3).

```rust
//! contention_bus.rs — memory-access (bus) cycle counting per instruction
//! (P18 §3.3): bus = 4·words + operand data accesses, clamped to the
//! rounded total. Mirrors decode.rs's dispatch; a gap here falls back to
//! "fully contended", never to "no contention". Prefetch refill at branch
//! targets is deliberately not modelled (≤8 cycles, inside the ±10% band).

/// Bus share of one instruction whose ST-rounded total is `rounded_total`.
pub(super) fn bus_cycles(bytes: &[u8], rounded_total: u32) -> u32 {
    match data_access_cycles(bytes) {
        Some(d) => (4 * (bytes.len() as u32 / 2) + d).min(rounded_total),
        None => rounded_total,
    }
}

/// Operand data reads/writes only (no fetches), or None when the opcode is
/// outside the classified set.
fn data_access_cycles(bytes: &[u8]) -> Option<u32> {
    let word = word_at(bytes, 0)?;
    match word >> 12 {
        0x0 => contention_bus_misc::group_0_data(word),
        0x1..=0x3 => move_data(word),
        0x4 => contention_bus_misc::group_4_data(bytes, word),
        0x5 => contention_bus_misc::group_5_data(word),
        0x6 => Some(if (word >> 8) & 0xF == 1 { 8 } else { 0 }), // bsr pushes
        0x7 if word & 0x0100 == 0 => Some(0),                    // moveq
        0x8 | 0x9 | 0xB | 0xC | 0xD => alu_data(word),
        0xE => shift_data(word),
        _ => None,
    }
}

const fn acc(long: bool) -> u32 { if long { 8 } else { 4 } }
fn is_mem(ea: EaMode) -> bool {
    !matches!(ea, EaMode::Dn | EaMode::An | EaMode::Imm)
}
```

**Classification table — exactly this; every row's encoding test is copied
from the corresponding `decode*.rs` arm (keep the masks identical):**

| Group (encoding as in decode*.rs) | data_access_cycles |
|---|---|
| `move/movea` (nibbles 1–3; long ⇔ nibble 2) | `(is_mem(src) as u32)·acc + (is_mem(dst) as u32)·acc` — dst from the same bits-11..6 fields `decode_move` reads; PC-relative/Imm dst → None like decode |
| `moveq` | 0 |
| `bra`/`Bcc` / `bsr` | 0 / 8 (pushes return PC) |
| `addx/subx` (`word & 0x0130 == 0x0100` under 0x9/0xD) | mem form (bit3 set): `3·acc(long)` (2 reads + 1 write); reg form: 0 |
| `abcd/sbcd` (packed form under 0x8/0xC, opmode 4) | mem: 12; reg: 0 |
| `exg` (0xC, opmodes 5/6) | 0 |
| `cmpm` (0xB, mode==1, opmodes 4–6) | `2·acc(opmode==6)` |
| ALU `<ea>,Dn` (opmodes 0–2, nibbles 8/9/B/C/D) | `is_mem(ea)·acc(opmode==2)` |
| `adda/suba/cmpa` (opmodes 3/7) | `is_mem(ea)·acc(opmode==7)` |
| `mulu/muls/divu/divs` (0xC/0x8 opmodes 3/7) | `is_mem(ea)·4` (word read) |
| ALU `Dn,<ea>` incl. `eor` (opmodes 4–6) | mem dst: `2·acc(opmode==6)` (RMW); Dn dst (eor): 0 |
| `andi/ori/eori to ccr/sr` (the 6 exact words) | 0 |
| static/dynamic bit ops, mem dst | `btst` 4 (read); `bchg/bclr/bset` 8 (RMW byte); reg dst 0 |
| immediates `addi/subi/andi/ori/eori` mem | `2·acc(long)`; `cmpi` mem: `acc(long)` (read only); Dn: 0 |
| `addq/subq` (0x5, size≠3) | mem: `2·acc(long)`; Dn/An: 0 |
| `Scc` mem / `DBcc` | 8 (1r+1w per PRM) / 0 |
| `clr/neg/negx/not` mem | `2·acc(long)` (the 68000 reads even for clr); Dn: 0 |
| `tst` | mem: `acc(size==2)`; else 0 |
| `tas` / `nbcd` mem | 8 / 8 (RMW byte); Dn: 0 |
| `jsr` / `jmp` / `lea` / `pea` | 8 / 0 / 0 / 8 |
| `movem`, n = `mask.count_ones()` (mask via `word_at(bytes, 2)?`) | store: `n·acc(long)`; load: `n·acc(long) + 4` (the 68000 does n+1 reads) |
| `link` / `unlk` / `rts` / `rtr` / `rte` | 8 / 8 / 8 / 12 / 12 |
| `trap` / `trapv` / `reset` / `stop` / `nop` / `swap` / `ext` / `move usp` | 20 (PC.l+SR.w push + vector read) / 0 / 0 / 0 / 0 / 0 / 0 / 0 |
| `move from sr` / `move to ccr/sr` | mem dst: 8 (1r+1w per PRM); mem src: 4; reg: 0 |
| anything else | None (→ fully-contended fallback) |

```rust
//! Wire schema + output assembly for `profile`. Moved out of
//! analyze_wire.rs when P18 added the region-aware contended estimate
//! (file-size ceiling; insn_out.rs precedent).

use schemars::JsonSchema;
use serde::{Deserialize, Serialize};

use crate::analyze::cycles::{self, Region};
use crate::types::Addr;

pub const PROFILE_LEG_TIMEOUT_MS: u64 = 20_000;
pub const PROFILE_MAX_RANGE: u32 = 65_536;

#[derive(Debug, Deserialize, JsonSchema)]
pub struct ProfileArgs {
    /// Run-from PC (breakpoint `pc = from` is armed and awaited).
    pub from: String,
    /// Run-to PC. Must differ from `from`; `to - from` ≤ 65536 bounds the
    /// static-disasm window (measurement itself is unbounded).
    pub to: String,
    /// Per-leg wait budget (reach `from`, then reach `to`), ms. Default 20000.
    pub timeout_ms: Option<u64>,
    /// Display region the code runs in, for the contended static estimate:
    /// "visible" (default — active display, Shifter steals bus slots; the
    /// worst case), "vblank" (full bus, no contention), "mixed" (code that
    /// runs across the whole frame). Does not affect measured_cycles.
    pub region: Option<RegionArg>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize, JsonSchema)]
#[serde(rename_all = "lowercase")]
pub enum RegionArg { Visible, Vblank, Mixed }

impl RegionArg {
    pub(crate) fn to_region(self) -> Region {
        match self {
            RegionArg::Visible => Region::Visible,
            RegionArg::Vblank => Region::Vblank,
            RegionArg::Mixed => Region::Mixed,
        }
    }
    pub(crate) fn name(self) -> &'static str {
        match self { RegionArg::Visible => "visible", RegionArg::Vblank => "vblank", RegionArg::Mixed => "mixed" }
    }
}

#[derive(Debug, Serialize, JsonSchema)]
pub struct ProfileOutput {
    pub from: String,
    pub to: String,
    /// Hatari-measured cycles summed over profiled addresses in
    /// [from, to) — interrupt/TOS time outside the range excluded. None
    /// only if no profiled address fell in range. GROUND TRUTH: includes
    /// real emulated bus contention.
    pub measured_cycles: Option<u64>,
    /// Executed-instruction count over the same range.
    pub instructions: Option<u64>,
    /// Static straight-line estimate for ONE pass from..to — contention-
    /// BLIND lower bound (fall-through branches; see tool description).
    pub static_cycles: u64,
    /// static_cycles with the STE Shifter bus-contention model applied to
    /// its memory-access share for `region` (ADR-P18): ×3/2 visible, ×1
    /// vblank, ×413/313 mixed. Together with static_cycles this brackets
    /// the expected cost; measured_cycles remains the truth.
    pub static_cycles_contended: u64,
    /// Memory-access (bus) share of static_cycles — what contention
    /// scales. bus/static ≈ how bus-bound the routine is.
    pub static_bus_cycles: u64,
    /// Region assumed by static_cycles_contended ("visible"|"vblank"|"mixed").
    pub region: String,
    /// Instructions the static model could not cost (counted at 4 cycles).
    pub static_unknown: usize,
    /// measured_cycles / 160256 (falls back to static_cycles_contended
    /// when measurement is absent).
    pub vbl_fraction: f64,
    /// The raw `profile save` file (ADR-5: bulk data stays on disk).
    pub profile_path: String,
    /// Always "paused" on success — profiling ends frozen at `to`.
    pub state: String,
}

/// Assemble the wire output (moved from analyze_profile.rs; pure —
/// the P18 unit-test seam for the fallback + contention wiring).
pub(crate) fn build_output(
    from: Addr,
    to: Addr,
    instructions: u64,
    measured_cycles: u64,
    estimate: cycles::CycleEstimate,
    region: RegionArg,
    path: std::path::PathBuf,
) -> ProfileOutput {
    let contended = cycles::contended_cycles(&estimate, region.to_region());
    let has_data = instructions > 0;
    let vbl_fraction =
        cycles::vbl_fraction(if has_data { measured_cycles } else { contended });
    ProfileOutput {
        from: from.to_string(),
        to: to.to_string(),
        measured_cycles: has_data.then_some(measured_cycles),
        instructions: has_data.then_some(instructions),
        static_cycles: estimate.cycles,
        static_cycles_contended: contended,
        static_bus_cycles: estimate.bus_cycles,
        region: region.name().to_string(),
        static_unknown: estimate.unknown,
        vbl_fraction,
        profile_path: path.display().to_string(),
        state: "paused".to_string(),
    }
}
```

## 9. Proposed ADR — append to `decisions.md` at implementation time

Use the **next free number** (ADR-34 if the log is still at ADR-33 — do not
renumber, do not edit `decisions.md` before implementation lands):

> ## 2026-07-XX — ADR-34: STE bus-contention model sharpens the static cycle estimate
>
> **Status:** accepted
> **Context:** P2's static 68000 estimate is contention-blind; on the ST(E)
> the Shifter steals bus slots during the 200 visible scanlines (~12
> cyc/word vs ~8 in the 113-line VBlank — STEIsNotDead's proven
> `ste_model.py`, via the m68000-cycles skill), so blind numbers understate
> visible-region cost by up to 50%. The measured Hatari-profiler path
> already includes real contention; only the estimate needed sharpening.
> **Decision:** Split each instruction's ST-rounded cost into bus cycles
> (4·instruction-words + operand data accesses, clamped to the total;
> classifier mirrors the decode dispatch) and internal cycles; scale only
> the bus share by a display-region factor — visible ×3/2 (the physical
> 12/8), vblank ×1, mixed ×413/313 (scanline-weighted). A static range
> cannot know its display region, so `profile` takes `region` (default
> `visible` = worst case, ste_model.py's own UNKNOWN policy) and returns
> blind + contended side by side — a bracket, not a single adjusted number.
> Classifier gaps fall back to fully-contended (exactly ste_model.py's flat
> behavior), never to no-contention. Per-instruction `cycles_est` in
> `disasm` stays blind (per-insn contended values would be false precision).
> **Alternatives considered:** ste_model.py's flat ×1.45-on-total (simplest,
> but adds ~45% to mul/div/shift internal cycles that never touch the bus;
> 1.45 is demonstrably just 1.5-on-bus diluted by a ~10% internal share);
> extending `decode*.rs` to return (total, bus) tuples (more invasive across
> three at-ceiling files, same result); inferring the region from the VBL
> counter at profile time (measured path already answers that; a static
> estimate is a what-if tool).
> **Consequences:** `profile` output gains `static_cycles_contended`,
> `static_bus_cycles`, `region` (and `vbl_fraction`'s no-measurement
> fallback becomes the contended value); blind semantics and the measured
> path are unchanged. The bus/total ratio doubles as a "how bus-bound is
> this routine" signal. Prefetch refill at branch targets is deliberately
> unmodelled (≤8 cycles, inside the model's ±10% honesty band).
