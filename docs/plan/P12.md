## 1. Deliverable in one sentence

The first **headerless** scheme end to end: a `zx0` `Depacker` (ZX0 v2
forward: interlaced Elias-gamma bit stream with backtrack, three-state

## 4. The ZX0 v2 format — pinned from dzx0.c (normative)

### 4.0 Version scope

ZX0 has two on-disk generations. **v2** (2021+, files produced by
`zx0` v2.x and by `salvador`) is the current standard and the only one P12
implements. **v1 "classic"** (`dzx0 -c`) differs in exactly one place: the
offset-MSB gamma is read *non-inverted* (§4.3). The **backwards** variant
(`zx0 -b`, for in-place 8-bit depacking) reverses stream and output
direction. Both are deferred (ADR-25): the format is headerless, so
variants are indistinguishable by inspection — if a real target needs one,
it becomes its own plugin id (`zx0-classic`, `zx0-b`) selectable via the
`depack` tool's `scheme` parameter; the seam is already there. A wrong
variant fed to this decoder fails closed (guards below), never
mis-decodes silently in practice (§6.2's gates measured 0/20000 random
buffers passing).

There is **no header, no magic, no stored length** — a `.zx0` file is the
raw bit/byte stream below, self-terminated by an end marker. All state:
`last_offset` (initialized to **1**), the bit register, and the
`backtrack` flag.

### 4.1 Stream model — one forward cursor, MSB-first bits, backtrack

A single **forward** byte cursor is shared by bit-register reloads and raw
byte reads (literal values and offset-LSB bytes). The bit reader
(`read_bit` in dzx0.c) — pin exactly:

```text
state: mask: u8 = 0, byte: u8, last: u8, backtrack: bool = false
take_byte(): next byte at the cursor (None if exhausted); also sets `last`
bit():
    if backtrack:            # set only after an offset-LSB byte (§4.3)
        backtrack = false
        return last & 1      # bit 0 of that LSB byte
    mask >>= 1
    if mask == 0:
        mask = 0x80
        byte = take_byte()?  # lazy reload — bit bytes appear in the file
    return byte & mask != 0  # MSB-first within each bit byte
```

### 4.2 Interlaced Elias gamma (`read_interlaced_elias_gamma`)

Control and data bits alternate, all through `bit()`:

```text
gamma(inverted):
    value = 1
    while bit()? == 0:                 # control 0 = "one more data bit"
        value = (value << 1) | (bit()? ^ inverted)
        if value > MAX_UNPACKED: None  # our guard: caps corrupt/all-zero
    return value                       # control 1 terminates; value >= 1
```

The guard is P12's addition (the C exits on file errors instead): an
all-zero input doubles `value` forever — cap it at `MAX_UNPACKED`
(imported from `crate::ripper::registry`; 16 MiB dwarfs every real gamma:
lengths are bounded by output size, offset MSBs by 256).

### 4.3 The state machine (`decompress` in dzx0.c)

```text
last_offset = 1
COPY_LITERALS:
    n = gamma(false)                       # n >= 1 always
    copy n raw bytes cursor -> output
    bit 1 -> COPY_FROM_NEW_OFFSET;  bit 0 -> COPY_FROM_LAST_OFFSET

COPY_FROM_LAST_OFFSET:
    n = gamma(false)
    copy n bytes from output[len-last_offset] (forward, per-byte —
        overlap replicates; last_offset 1 = RLE of the previous byte)
    bit 0 -> COPY_LITERALS;  bit 1 -> COPY_FROM_NEW_OFFSET

COPY_FROM_NEW_OFFSET:
    msb = gamma(true)                      # INVERTED data bits (v2)
    if msb == 256: END — return (output, cursor position = consumed)
    if msb > 256: None                     # corrupt (encoder max is 255)
    lsb = take_byte()
    last_offset = msb*128 - (lsb >> 1)     # range 1..=32640
    backtrack = true                       # bit 0 of lsb = first bit of...
    n = gamma(false) + 1                   # ...this length gamma; n >= 2
    copy n bytes from output[len-last_offset]
    bit 1 -> COPY_FROM_NEW_OFFSET;  bit 0 -> COPY_LITERALS
```

Decoding **starts in COPY_LITERALS with no leading indicator bit** — the
encoder's first block indicator is swallowed at write time (§6.1 rule 1),
so every stream begins directly with a literal-length gamma. Guards on
every block, all → `None`, never a panic: cursor exhaustion; gamma cap
(§4.2); `msb > 256`; `last_offset > output.len()` (copy from before the
start — dzx0's "Invalid data" exit); `output.len() + n > MAX_UNPACKED`.
Offset arithmetic check (matches the encoder, §6.1): encoder writes
`msb = (offset-1)/128 + 1`, `lsb = (127 - (offset-1)%128) << 1`, so
`msb*128 - (lsb>>1) = offset` exactly; `msb ∈ 1..=255` ⇒ offset ∈
1..=32640; offset 0 is unrepresentable.

**Consumed:** the number of bytes the cursor has read when the end marker
fires. This is the packed stream's exact length — ZX0 does not record it
anywhere, so the decoder is the only source (the `depack` tool reports it).

### 4.4 Reading aid — Z3 = `7B 41 42 43 FA 55 55 80` → `b"ABCABC"`

Bit byte `0x7B` = `0,1,1,1,1,0,1,1` (MSB first). Literal gamma: control 0,
data 1 → 3; control 1 → stop ⇒ n=3. Literals `41 42 43` → "ABC". State
bit 1 → new offset. MSB gamma (inverted): control 1 ⇒ msb=1 (≠256). LSB
byte `0xFA`: offset = 128 − (0xFA>>1) = 128 − 125 = **3**; backtrack set.
Length gamma: backtrack bit = 0xFA&1 = 0 (control), data = next 0x7B bit
= 0 → value 2; control 1 → stop ⇒ n = 2+1 = 3. Copy 3 from offset 3 →
"ABC" ⇒ "ABCABC". State bit (last 0x7B bit) 1 → new offset. MSB gamma
inverted: reload `0x55` twice then `0x80` — eight (0, data 1→inv 0) pairs
double value to 256, control 1 stops ⇒ END. Consumed = 8 = whole blob.

## 5. Design + new code

### 5.0 THE decision — how a headerless scheme plugs in (ADR-25)

ZX0 cannot participate in the magic-scan half of the ADR-2 recursion
engine: there is nothing to search for, and attempting a decode at every
byte offset of a 4 MB image is O(n·decode) and false-positive-prone.
Resolution, two complementary paths, **neither touching the engine**:

1. **Auto-engine (recursion): whole-buffer-exact gate.** `Zx0::try_unpack`
   attempts a decode at **offset 0 only** and succeeds only when the
   stream consumed **the entire buffer** and produced non-empty output.
   Random/garbage buffers essentially never pass (measured 0/20000 random
   1–64-byte buffers at spec time); ST RAM images never do (they don't end
   exactly at an end marker). What DOES pass: a depacked inner buffer that
   *is* a bare `.zx0` file — i.e. packer-in-packer, the exact case
   recursion exists for (§6.3's atomik⊃zx0 proof). Cost: one bounded
   decode attempt per scanned buffer, O(buffer) worst case — negligible
   next to the detectors.
2. **Explicit path: the `depack` tool.** In-RAM ZX0 streams sit at
   arbitrary addresses the *agent* locates (disasm shows a pointer;
   `search_memory` finds a structure). `depack(addr, scheme)` slices a
   window at that address, runs the named depacker **prefix-tolerantly**
   (trailing RAM after the stream is fine), and — because the dominant ZX0
   payload is *raw* screen/music/code data no detector can match — always
   returns a handle to the **whole depacked blob** (a synthetic `raw`
   finding, index 0) alongside whatever the detectors find in it, all in
   the standard last-scan store so `extract`/paging just work. Data stays
   server-side; the agent sees compact findings and file paths (ADR-5).

The seam that makes path 2 scheme-agnostic is one **additive, object-safe
default method** on `Depacker` (§5.1): headerless schemes override it;
magic-scanning schemes get it for free. A validating heuristic detector
(option B in the design discussion) is rejected: bit-granular starts make
candidate generation quadratic-ish, and a plausibility gate weak enough to
find real streams admits false positives — the explicit path costs the
agent one tool call and is exact. Adding a *future* headerless scheme
(LZSA, Shrinkler, `zx0-b`) is back to one plugin file + one registry line.

### 5.4 `src/ripper/plugins/zx0_decode.rs` + `zx0.rs` — NEW

`zx0_decode.rs` module doc: semantic port of einar-saukas/ZX0 v2.2
`dzx0.c` (§4; v1-classic/backwards deferred, §4.0/ADR-25). Pin these
shapes:

```rust
use crate::ripper::registry::MAX_UNPACKED;

/// §4.1: one forward cursor shared by bit reloads and raw reads.
struct Stream<'a> {
    data: &'a [u8],
    pos: usize,
    mask: u8,        // 0 = register empty (initial state)
    byte: u8,
    last: u8,
    backtrack: bool,
}

impl<'a> Stream<'a> {
    fn new(data: &'a [u8]) -> Self { /* pos 0, mask 0, backtrack false */ }
    fn take_byte(&mut self) -> Option<u8>       // §4.1; records `last`
    fn bit(&mut self) -> Option<bool>           // §4.1 verbatim (backtrack first)
    fn gamma(&mut self, inverted: bool) -> Option<u32>  // §4.2 incl. cap
}

/// Forward per-byte copy; recomputes src each byte so overlap replicates
/// (offset 1 = RLE). memmove/copy_within would BREAK runs — keep the loop.
fn copy_from(out: &mut Vec<u8>, offset: usize, n: usize) -> Option<()> {
    if offset == 0 || offset > out.len() || out.len().checked_add(n)? > MAX_UNPACKED {
        return None;
    }
    for _ in 0..n {
        out.push(out[out.len() - offset]);
    }
    Some(())
}

fn literals(s: &mut Stream, out: &mut Vec<u8>, n: usize) -> Option<()>
    // n raw bytes cursor -> out; caps at MAX_UNPACKED like copy_from

/// One copy event (§4.3). Returns Some(true) iff the end marker was read
/// (only reachable with new_offset).
fn copy_event(
    s: &mut Stream,
    out: &mut Vec<u8>,
    last_offset: &mut usize,
    new_offset: bool,
) -> Option<bool>

/// §4.3 entry. Decodes a ZX0 v2 stream starting at data[0]; trailing
/// bytes after the end marker are ignored. Returns (unpacked, consumed).
/// None = corrupt/truncated/absurd — never a panic.
pub(crate) fn decrunch(data: &[u8]) -> Option<(Vec<u8>, usize)> {
    let mut s = Stream::new(data);
    let mut out = Vec::new();
    let mut last_offset = 1usize;
    loop {
        let n = s.gamma(false)? as usize;
        literals(&mut s, &mut out, n)?;
        let mut new_offset = s.bit()?;
        loop {
            if copy_event(&mut s, &mut out, &mut last_offset, new_offset)? {
                return Some((out, s.pos));
            }
            new_offset = s.bit()?;
            if !new_offset {
                break; // -> COPY_LITERALS
            }
        }
    }
}
```

`zx0.rs` — the plugin, mirroring `pack_ice.rs` style (module doc states
the headerless design, the exact gate, and the deferred variants):

```rust
use super::zx0_decode::decrunch;
use crate::ripper::Depacker;
use crate::types::PluginId;

pub struct Zx0;

impl Depacker for Zx0 {
    fn id(&self) -> PluginId {
        PluginId::new("zx0")
    }
    fn describe(&self) -> &'static str {
        "ZX0 v2 depacker — headerless: auto-rip unpacks only a whole-buffer-exact \
         stream; use the depack tool with an explicit address for streams inside RAM"
    }
    /// Auto-engine gate (ADR-25): offset 0, FULL consumption, non-empty.
    fn try_unpack(&self, data: &[u8]) -> Option<Vec<u8>> {
        let (out, consumed) = decrunch(data)?;
        (consumed == data.len() && !out.is_empty()).then_some(out)
    }
    /// Explicit path: trailing bytes after the stream are fine.
    fn try_unpack_prefix(&self, data: &[u8]) -> Option<(Vec<u8>, usize)> {
        decrunch(data).filter(|(out, _)| !out.is_empty())
    }
}
```

```rust
#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct DepackArgs {
    /// Bus address where the packed stream starts ("$4A000", "0x4A000", or decimal).
    pub addr: String,
    /// Window length from addr in bytes (default: to the end of RAM).
    pub len: Option<usize>,
    /// Depacker plugin id (see list_ripper_plugins), e.g. "zx0", "pack-ice".
    pub scheme: String,
    /// Depack→rescan depth for the unpacked buffer (default 2, max 4). 0 = detectors only.
    pub depth: Option<u8>,
}

#[derive(Debug, serde::Serialize, schemars::JsonSchema)]
pub struct DepackOutput {
    /// Pass to `rip {scan_id}` to page findings beyond this first page.
    pub scan_id: u64,
    pub scheme: String,
    pub addr: String,
    /// Bytes of the window the depacker consumed — for headerless schemes
    /// (zx0) the exact packed-stream length; magic-scanning schemes
    /// attribute the whole window.
    pub consumed: usize,
    pub unpacked_len: usize,
    pub total: u32,
    /// First page (limit 32). findings[0] is ALWAYS the whole depacked
    /// blob (kind "raw", via=[scheme]) — extract it for the raw bytes.
    pub findings: Vec<FindingOut>,
    pub has_more: bool,
}
```

Pure core (free fns, no `self`, no async — this is the testable seam):

```rust
/// Window bounds within the snapshot. Err = agent-facing message.
fn window(mem: &MemImage, addr: Addr, len: Option<usize>) -> Result<(usize, usize), String>
    // off = addr - base (reject addr < base or off >= mem.len(), message
    // names addr and the valid range); end = min(off + len.unwrap_or(rest),
    // mem.len()); reject len == Some(0).

/// Depack + provenance finding + rescan, all pure CPU (runs inside
/// spawn_blocking). None = the scheme does not decode at the window start.
pub(crate) fn depack_and_scan(
    reg: &Registry,
    mem: &Arc<MemImage>,
    off: usize,
    end: usize,
    plugin: PluginId,
    depth: u8,
) -> Option<(usize, usize, Vec<Finding>)> {
    let (out, consumed) = reg.unpack_prefix(plugin, &mem.bytes()[off..end])?;
    let unpacked = Arc::new(MemImage::new(out, Addr::new(0)));
    let via = [plugin];
    let label = format!(
        "{plugin} depacked blob ({consumed} packed -> {} unpacked bytes)",
        unpacked.len()
    );
    let mut findings = vec![Finding::whole_buffer(&unpacked, plugin, &via, label)];
    findings.extend(reg.scan_via(unpacked, None, depth, &via));
    Some((consumed, /* unpacked_len via findings[0].len */ findings[0].len, findings))
}
```

so `addr()` is `None` by construction — pinned by §5.5.3's `scan_via`
test.)

### 6.1 The pinned assembler (mirror of compress.c's bit emitter)

Unlike ICE/Atomik (consumption-order scripts), the ZX0 assembler mirrors
the **encoder's** write path — `write_bit`/`write_byte` from compress.c —
because bit bytes are allocated lazily *in place* in the forward stream.
Pin exactly:

```rust
/// compress.c's write_bit/write_byte, verbatim semantics (§6.1 rules).
struct Zx0Asm {
    out: Vec<u8>,
    bit_mask: u8,     // 0 = no open bit byte
    bit_index: usize, // position of the open bit byte in `out`
    backtrack: bool,  // next bit ORs into out.last_mut() bit 0
}
```

Serialization rules (normative):

1. `backtrack` starts **true**: the very first `write_bit` is swallowed
   (compress.c's initial-backtrack trick — with an empty buffer the first
   block's indicator, always the literal 0, writes nothing). Consequence:
   a script MUST start with a `literals` event, and the decoder (§4.3)
   starts at COPY_LITERALS with no indicator.
2. `write_byte(v)`: push `v`.
3. `write_bit(b)`: if `backtrack` { if b { `*out.last_mut() |= 1` }
   `backtrack = false` } else { if `bit_mask == 0` { `bit_mask = 0x80;
   bit_index = out.len(); out.push(0)` } if b { `out[bit_index] |=
   bit_mask` } `bit_mask >>= 1` }. (Bit bytes are thus interleaved into
   the stream lazily, exactly where the decoder's reload finds them.)
4. `gamma(value, inverted)`: let `i` = the power of two one below
   `value`'s top bit (`i = 2; while i <= value { i <<= 1 } i >>= 2`);
   while `i != 0`: `write_bit(0)`, `write_bit(((value & i != 0) as u8) ^
   inverted)`, `i >>= 1`; finally `write_bit(1)`.

Event helpers (each asserts state-machine legality is the CALLER's job):

```rust
fn ev_literals(a: &mut Zx0Asm, p: &[u8])           // bit 0; gamma(len,false); bytes
fn ev_copy_last(a: &mut Zx0Asm, n: usize)          // bit 0; gamma(n,false)
fn ev_copy_new(a: &mut Zx0Asm, off: usize, n: usize) {
    // bit 1; gamma((off-1)/128 + 1, true);
    // write_byte(((127 - (off-1)%128) << 1) as u8);
    // a.backtrack = true; gamma(n - 1, false)
}
fn ev_end(a: &mut Zx0Asm)                          // bit 1; gamma(256, true)
```

Packers:

```rust
/// One literal run + end. The payload appears VERBATIM in the blob —
/// never use for a payload a detector could match.
fn zx0_pack_literal(payload: &[u8]) -> Vec<u8>     // assert !payload.is_empty()

/// Degas-safe (amended per ADR-24; the original construction was
/// falsified in implementation): the split must land INSIDE the palette,
/// not merely after the res word — the detector scans every even offset
/// and PAL[0] = 0x0000 doubles as a res word, so any blob that carries
/// PAL[0..16] (or PAL[1..16]) as one verbatim literal run aliases as a
/// PI1 wherever that run starts. Emits:
///   literals payload[..1];  copy_last(1)   — payload[1] via the INITIAL
///                                            last_offset 1;
///   literals payload[2..12]                — PAL[0..5], 10 bytes;
///   copy_new(3, 2)                         — payload[12..14] == payload
///                                            [9..11] (PAL fixture: 0x707
///                                            == 0x007-lo ++ 0x770-hi);
///   literals payload[14..];  end.
/// No surviving palette fragment can fill a 32-byte palette window: any
/// window over payload[2..12] contains the copy_new offset byte 0xFB
/// (poison in both parities: 0xFBxx has the top nibble set; 0xxxFB pairs
/// with payload[11] = 0x70 → 0x70FB), and payload[14..]'s aligned words
/// are real PAL words (none a res word) with the screen's 0xFFxx words
/// close behind. Verification vector (bit-exact, simulator cross-checked
/// against Z1–Z6): blob[..18] ==
///   A1 00 39 00 00 07 00 00 70 00 07 07 70 FB 54 40 44 35
/// and blob[32036..] == FF FF 55 58. Pinned lengths are UNCHANGED:
/// 61 stream bits → 8 bit bytes, + 32 031 payload bytes + 1 offset byte
/// = 32 040 (the original was 51 bits → 7 bit bytes + 32 033 payload =
/// the same 32 040). The residual even offsets whose safety is by bit-
/// byte VALUE, not structure (14/16 → words 0x5440/0x4435), are pinned
/// by the §6.4-3 darkness guard, which replaces this comment's proof
/// burden with a mechanical assertion.
fn zx0_pack_pi1(payload: &[u8]) -> Vec<u8>
    // assert payload[0] == payload[1] && payload[9..11] == payload[12..14]
```

## 11. ADR-25 — append to `decisions.md` (verbatim; fill only the date)

```markdown
## 2026-07-XX — ADR-25: ZX0 depacker — headerless schemes get an exact-gated auto path plus an explicit depack tool

**Status:** accepted
**Context:** The DHS "Uhane" demo packs data with ZX0 (Einar Saukas's
format, Emmanuel Marty's decompressors) — the dominant modern
cross-platform compressor, and the first scheme in the roster with NO
magic header, no stored lengths, nothing to scan for. The ADR-2/ADR-14
recursion engine is magic-driven (scan → depack → rescan), so ZX0 cannot
be auto-located in a RAM image; and its typical payload is raw
screen/music/code data that no detector matches, so even a successful
depack is invisible unless the unpacked bytes themselves become a handle.
**Decision:** Two complementary paths, engine untouched. (1) **Auto
engine: whole-buffer-exact gate.** `Zx0::try_unpack` decodes at offset 0
only and succeeds only if the stream consumed the entire buffer and
produced non-empty output. This makes recursion work for the real nested
case (a depacked inner buffer that IS a bare .zx0 file — proven by the
atomik⊃zx0⊃PI1 fixture, via == ["atomik","zx0"]) at essentially zero
false-positive risk (0/20000 random buffers passed the gate at spec time)
and O(buffer) cost. (2) **Explicit path: the `depack` tool**
(addr, scheme, len?, depth?). The agent locates the stream (disasm,
search_memory), the server slices a window at that address, runs the named
depacker PREFIX-tolerantly via a new `Depacker::try_unpack_prefix` default
method (additive, object-safe; default = try_unpack over the whole window,
overridden by headerless schemes to return (unpacked, consumed)), then
stores results in the standard last-scan store: findings[0] is a synthetic
whole-buffer Raw finding (`Finding::whole_buffer`) carrying via=[scheme] —
so `extract` materializes the raw depacked blob, detector findings inside
it arrive with honest provenance and no fake bus address
(`Registry::scan_via` exposes the engine's existing via parameter), and
paging reuses rip's scan_id. Consumed-length is reported — ZX0 stores it
nowhere, the decoder is its only source. (3) **Version scope: ZX0 v2
forward standard only** (the format of zx0 v2.x and salvador), pinned from
einar-saukas/ZX0 v2.2 dzx0.c with fixtures generated/verified by the
reference binaries themselves. v1 "classic" (offset gamma not inverted)
and the backwards variant are deferred: headerless means variants are
indistinguishable by inspection; when a real target needs one it becomes
its own plugin id selectable through the tool's `scheme` parameter.
**Alternatives considered:** a validating heuristic detector attempting
decodes at candidate offsets (rejected: bit-granular starts make candidate
generation explosive, and any plausibility gate loose enough to find real
streams admits false positives — the explicit call is exact and costs one
round trip); windowed `rip` (addr/len arguments) instead of a new tool
(rejected: muddles rip's whole-RAM contract and cannot return the depacked
blob when no detector matches — the dominant ZX0 payload is headerless raw
data); requiring the agent to supply the unpacked length (unnecessary —
the stream self-terminates); registering nothing in the auto engine
(rejected: packer-in-packer with a bare .zx0 inner file is real and the
gate is free); a zx0 region detector (impossible without decoding —
violates the ADR-19 cheap-detector invariant).
**Consequences:** The P3-frozen `Depacker` trait gains one default method
— still object-safe, zero impact on existing impls; the registry gains two
capability lookups (unpack_prefix, scan_via — the ADR-12 render_png
precedent), not engine changes; tool count +1. "Add a headerless scheme"
is now one plugin file + one registry line, same as magic schemes; future
LZSA/Shrinkler/zx0-b ports reuse the seam unchanged. Known limits are
explicit and tested: a ZX0 stream the agent cannot locate is not found
(auto rip stays silent about arbitrary in-RAM streams by design), and
wrong-variant streams fail closed rather than mis-decode.
```
