## 4. The three formats — pinned from the cited asm (normative)

Shared conventions: all header integers **big-endian**; every bound
violation, truncated stream, or absurd header is `None` — never a panic,
never an error (`Depacker` contract, ADR-2/ADR-14). `MAX_UNPACKED` is
imported from `crate::ripper::registry`.

### 4.A Atomik 3.5 (`ATM5`)

#### 4.A.1 Header (12 bytes)

| Offset | Size | Field | Semantics |
|---|---|---|---|
| +0 | 4 | magic | `b"ATM5"` (`41 54 4D 35`) |
| +4 | 4 | `decrunched` u32 BE | exact unpacked output length |
| +8 | 4 | `stream_len` u32 BE | length of the packed stream **after** the header (contrast Pack-Ice, whose length field includes the header). Total blob = `12 + stream_len`. |

Sanity gates (`parse_header`, shared by both plugins): magic matches;
`1 <= decrunched <= MAX_UNPACKED`; `stream_len >= 6` (picture byte +
bit-init byte + minimum chunk trailer); whole region fits:
`o + 12 + stream_len <= bytes.len()`. Any violation → `None`.

#### 4.A.2 Stream model — backward, recycled-sentinel bit register

The stream `blob[12 .. 12+stream_len]` is consumed **end toward start**;
output is written **end toward start** (like Pack-Ice). One descending byte
cursor `pos` is shared by the bit register and all raw-byte reads.

**Init order (consumption):** (1) `pic = take_byte()` — the stream's LAST
byte is the picture-algorithm count (`depack35.s` reads or skips it in both
builds; the cruncher always writes it). **If `pic != 0`, return `None`** —
picture-mode post-processing is out of scope (§4.A.7). (2)
`reg = take_byte()` **raw — no sentinel added** (like ICE's init).

**Bit reader** (from `get_bit2`'s `add.b d7,d7 / beq → move.b -(a6),d7;
addx.b d7,d7`) — pin exactly. This differs from ICE in ONE way: at
register exhaustion the shifted-out bit is **recycled into bit 0 of the
reloaded register** instead of a forced `1`:

```text
carry = reg & 0x80 != 0
reg <<= 1                              (u8, high bit discarded)
if reg == 0:                           (register exhausted)
    next = take_byte()                 (None if pos would underflow)
    bit  = next & 0x80 != 0            (the DELIVERED bit is the new
                                        byte's top bit)
    reg  = (next << 1) | carry         (old carry recycled into bit 0)
    return bit
return carry
```

On well-formed streams the recycled bit is always the encoder's `1`
sentinel, so observable behavior equals ICE's reader: the **init byte**
carries up to 7 data bits at the top, then a `1` sentinel, then
**zero-fill** (NOT 1-fill — with the recycled-carry scheme a 1-fill would
deliver the sentinel as a data bit; this is why §6.1's assembler 0-fills,
the one place it deviates from P5 §6.3 rule 2); every **reloaded** byte
carries exactly 8 data bits. `bits(n)` folds MSB-first (`addx d5,d5`);
`bits(0) == 0` reading nothing. `get_bit2` with `moveq #N,d6` reads N+1
bits — all bit counts below are already converted.

#### 4.A.3 Chunk structure (`take_type` → `make_jnk`)

The stream is a sequence of **chunks**, each with a trailer read (in
consumption order) before its body:

1. 1 bit: **special-offset flag**. If 1: read 1 raw byte `spec_byte`, then
   build the 7-entry odd table: `d1 = 1; for slot in 0..7 { if d1 ==
   spec_byte { d1 += 2 } odd[slot] = d1; d1 += 2 }` (the first 7 odd
   numbers with the one equal to `spec_byte` skipped).
2. 1 bit: **frequency-table flag**. If 1: read 16 raw bytes into
   `freq[0..16]` **in read order** (`freq[0]` = first byte taken).
3. 1 raw byte `d3` — the unary length threshold for this chunk.
4. 2 raw bytes `hi`, `lo` (in that read order): `chunk = (hi << 8) | lo` =
   this chunk's output byte count. Gates: `chunk == 0 → None`;
   `chunk > write → None`. `stop = write - chunk`.

**Chunk body** — while `write > stop`, read 1 flag bit:

- flag `0` → **literal**: one raw byte from the stream cursor →
  `write -= 1; out[write] = byte`.
- flag `1` → **code** (§4.A.4).

After the loop, require `write == stop` (a match overshooting the chunk
boundary is corrupt → `None`; the asm never checks, valid streams never
overshoot). Then: if `pos == 0` (all stream bytes consumed) the file is
done — require `write == 0`, else `None`. Otherwise decode the next chunk.

#### 4.A.4 Code event: length, then special-op or match

**Length code** (`take_lenght` + escalation): count zero bits; a `1` after
`z <= d3` zeros → `len_code = z`. If `d3 + 1` zeros arrive with no `1`,
escalate: `v = bits(4)`; if `v != 0` → `len_code = v + d3`; else
`v = bits(8)`; if `v != 0` → `len_code = v + 15 + d3`; else
`len_code = bits(14) + 270 + d3`.

**If `len_code == 0`**, read 1 bit:
- bit `0` → 2-byte match: `sel = bits(2)` (selectors 0..3), go to match
  with `copy_len = 2`.
- bit `1` → **special single byte**: `v = bits(4)`;
  - frequency mode (this chunk has a freq table): byte = `freq[v]`;
  - else (delta mode): `prev = out[write]` (the byte just written — if
    `write == out.len()` nothing has been written yet → `None`);
    `delta = if v >= 8 { v - 16 } else { v }` (signed 4-bit);
    `byte = prev.wrapping_sub(delta)`.
  - `write -= 1; out[write] = byte`; done (no match).

**Else** `sel = bits(3)` (selectors 0..7), match with
`copy_len = len_code + 2`.

#### 4.A.5 Match offset (`contus` + `decrun_table`)

```text
BASES: [32, 96, 352, 864, 1888, 3936, 8032]   (dc.w 32, 32+64, +256, +512,
                                               +1024, +2048, +4096)
XBITS: [0, 1, 3, 4, 5, 6, 7, 8]               (the dc.b row)
```

- **Normal mode** (no special-offset table this chunk):
  `val = bits(XBITS[sel] + 5)` (the asm's `addq #4,d6` + get_bit2's `+1`).
- **Special-offset mode**: `hi = bits(XBITS[sel] + 1)`; `v3 = bits(3)`;
  low nibble/byte `lo` = if `v3 < 7` → `odd[v3]`; else 1 more bit: `0` →
  `spec_byte` (the full byte, OR-merged); `1` → `bits(3) * 2` (even
  values). `val = ((hi << 4) & 0xFFFF) | lo as u32` (plain bit-or — the
  asm's `or.b`; the encoder guarantees no meaningful overlap).
- Both modes: if `sel > 0` → `val += BASES[sel - 1]`. (Ranges are
  contiguous 0..16223; `val` fits a word — no sign games.)

**Copy** (`lea 1(a5,d5.w),a4` + descending pre-decrement pair): distance is
`val + 1`; the copy is byte-by-byte **descending** so overlaps replicate
(val 0 → distance 1 → single-byte RLE run, exactly ICE's raw −1 case):

```text
guards: copy_len <= write            (else None)
for each of copy_len bytes:
    write -= 1
    src = write + val + 1            (src > write always; may exceed buffer)
    if src >= out.len(): None
    out[write] = out[src]
```

#### 4.A.7 What the reference has that we deliberately drop

The **picture algorithm** (`PIC_ALGO`, `decod_picture`): files whose
trailing count byte ≠ 0 store screens bitplane-transformed with an offset
table at the tail of the *decoded* output; without the inverse transform
the output is wrong, so we **fail closed**: `pic != 0 → None` (a wrong
picture is worse than none; follow-up if real targets need it). The
`MODE=1` in-place variant and `RESTORE_SPACE` margin save/restore —
irrelevant, we decode to a fresh `Vec`. The **`ATOM` magic** (Atomik
3.1/3.3): a *different, incompatible* scheme that shares its magic with
Thunder datafiles (DEPACK.C resolves it by asking the user) — deferred;
state all three drops in the module doc comment.

### 4.B PowerPacker (`PP20`)

#### 4.B.1 File layout — note: NO packed-length field

| Offset | Size | Field |
|---|---|---|
| +0 | 4 | magic `b"PP20"` (`50 50 32 30`) |
| +4 | 4 | efficiency table `eff[0..4]` — offset bit-count per match code (canonical `09 0A 0C 0D`; ppdec.s: "any crunch efficiency") |
| +8 | E−12 | packed data: big-endian u32 longs |
| E−4 | 4 | trailer u32 BE: bits 31..8 = `out_len` (24-bit unpacked length), bits 7..0 = `skip` (unused bits in the last data long) |

`E` (blob end) is **not recorded anywhere** — PowerPacker relies on the
file length. §4.B.4 pins how we derive it. Sanity gates: magic; each
`eff[i]` in `4..=14` (rejects "PP20" text false-positives hard); trailer:
`skip < 32`, `1 <= out_len <= MAX_UNPACKED`; `E - o >= 16` and
`(E - o) % 4 == 0` (header 8 + ≥1 data long + trailer; PP totals are
always ≡ 0 mod 4).

#### 4.B.2 Stream model — LSB-first bits in BE longs, read from the end

Data longs are consumed **from the trailer backward** (`move.l -(a0)`);
within each long bits are consumed **LSB-first** (`lsr.l #1,d5`, sentinel
at bit 31 via `roxr`). Multi-bit values fold **MSB-first** (`roxl.l #1,d1`
— the first bit read is the value's high bit). Before anything else,
`skip` bits are read and discarded. Output is written end → start; there
is **no separate byte cursor** — literal bytes are 8-bit values in the bit
stream.

Rust model (no sentinel needed — an explicit counter is equivalent):
`buf: u32`, `n: u32`; `bit()`: if `n == 0` load the previous long (BE) or
`None` if the data region is exhausted, `n = 32`; return `buf & 1`,
`buf >>= 1`, `n -= 1`. `bits(k)` folds MSB-first.

#### 4.B.3 Decode loop (`PP2.S`)

```text
write = out_len
while write > 0:
    if bit() == 0:                         # literal run
        run = 0
        loop: c = bits(2); run += c; until c != 3
        repeat run+1 times:
            if write == 0: None
            write -= 1; out[write] = bits(8)
        if write == 0: return out          # done — no trailing match
        # NO flag bit: a match ALWAYS follows a literal run
    code = bits(2)
    if code == 3:
        nbits = if bit() == 1 { eff[3] } else { 7 }
        off   = bits(nbits)
        len   = 5
        loop: c = bits(3); len += c; until c != 7
    else:
        off = bits(eff[code]); len = code + 2
    if len > write: None
    repeat len times:                      # descending; overlap replicates
        write -= 1
        src = write + off + 1
        if src >= out_len: None
        out[write] = out[src]
```

(off 0 → distance 1 → RLE. The `cmp.l a3,a2 / bcs` loop conditions map to
`while write > 0` + the mid-run exhaustion checks above.)

#### 4.B.4 End derivation (the missing-length workaround — pin exactly)

For a magic at offset `o` in buffer `bytes`, up to **two** candidate ends,
tried in this order:

1. **zero-trim end** `e1`: let `z` = one past the last non-zero byte of
   `bytes` at index ≥ `o` (if none, no candidate). `e1` = the smallest
   `e in z..z+4` with `(e - o) % 4 == 0` and `e <= bytes.len()`. (A valid
   trailer never ends in four zero bytes — `out_len == 0` is rejected —
   so the real end is within 3 bytes above the last non-zero byte.)
2. **buffer end** `e2`: the largest `e <= bytes.len()` with
   `(e - o) % 4 == 0`.

Deduplicate (`e1 == e2` is the common whole-file case). A candidate is
kept only if the §4.B.1 trailer gates pass at that end. The **detector**
reports the first kept candidate (its extent is therefore *estimated* —
say so in the label). The **depacker** attempts a full decode per kept
candidate in order and returns the first success. Consequence (goes in
ADR-19): a PP20 blob followed by other non-zero data in the same buffer is
missed (both ends wrong) or mis-extended by the detector — acceptable;
PP20 simply does not carry its length, and the dominant cases (whole file;
blob planted in zeroed RAM) both work. Tests pin them (§6.2).

#### 4.B.5 What we deliberately drop

`PX20` (encrypted PowerPacker — `pp_Decrypt`'s XOR needs a password-derived
key we don't have) and `PPMT`: not detected, not depacked — deferred, in
the module doc comment. Only `PP20` is recognized.

### 4.C RNC ProPack (`RNC\x01`, `RNC\x02`)

#### 4.C.1 Header (18 bytes) — shared by both methods

| Offset | Size | Field |
|---|---|---|
| +0 | 3 | magic `b"RNC"` (`52 4E 43`) |
| +3 | 1 | `method`: `0x01` or `0x02` |
| +4 | 4 | `unpacked` u32 BE |
| +8 | 4 | `packed` u32 BE — stream length after this header |
| +12 | 2 | `crc_unp` u16 BE — CRC-16 of the unpacked data |
| +14 | 2 | `crc_pack` u16 BE — CRC-16 of `blob[18 .. 18+packed]` |
| +16 | 1 | `leeway` (in-place headroom — ignored) |
| +17 | 1 | `chunks` (ignored; the decode loops on output position) |

**CRC-16** (from `RNC_2.S .rnc239`, `eori #$A001`): init `0`, reflected,
poly `0xA001` — i.e. per byte `crc ^= b; 8 × { crc = if crc & 1 != 0 {
(crc >> 1) ^ 0xA001 } else { crc >> 1 } }`. Standard CRC-16/ARC: pin with
the check value `crc16(b"123456789") == 0xBB3D`.

Sanity gates (`parse_header`): magic + method; `1 <= unpacked <=
MAX_UNPACKED`; `packed >= 2`; region fits (`o + 18 + packed <=
bytes.len()`); **and `crc16(payload) == crc_pack`** — the packed CRC is
checked at candidate time (both plugins; near-free, kills false positives
dead). After decode, both methods additionally require
`out.len() == unpacked && crc16(&out) == crc_unp` (RNC_1_2.S skips CRCs,
RNC_2.S checks both; we check both uniformly — dernc-style, note in
ADR-19).

#### 4.C.2 Method 1 — bit model: LSB-first over little-endian u16 words

Forward stream. The bit buffer holds ≥16 valid bits from **little-endian
16-bit words**; bits are consumed LSB-first; multi-bit *values* are read
as the low `n` bits verbatim (LSB-first — contrast PP/ICE/Atomik).
Literal runs are **raw bytes** interleaved at the current lookahead
position. Pin this exact state machine (traced from `.rnc1208/.rnc1217/
.rnc1219/.rnc120D`; it is also exactly dernc.c's reader):

```text
state: p (byte index of the lookahead word), buf: u32, count: u32
init:    buf = le16(stream, 0); count = 16; p = 0
le16(s, at): out-of-range bytes read as 0x00      (§4.C.6)
peek(n)  = buf & ((1 << n) - 1)                   (n <= 16)
advance(n): buf >>= n; count -= n
            if count < 16: p += 2; buf |= le16(stream, p) << count;
                           count += 16
read(n)  = peek(n) then advance(n)
fix()    : count -= 16; buf &= (1 << count) - 1   (after a literal run:
           buf |= le16(stream, p) << count;        re-splice the lookahead
           count += 16                             word at the new p)
```

Invariant: `count ∈ 16..=31`; the low `count-16` bits belong to the word
before `p`; the word at `p` is spliced but 0 of its bits consumed — which
is why a literal run may claim the bytes at `p` and `fix()` afterwards.

#### 4.C.3 Method 1 — Huffman tables (`.rnc121C`)

`read_table`: `count = read(5)` (0 → empty table, valid only if never
consulted); then `count` × `read(4)` code lengths. Build canonical codes,
lengths ascending, symbol order within a length, codes assigned from a
32-bit left-justified accumulator; stored **bit-reversed** for LSB-first
matching:

```text
codeb: u32 = 0
for len in 1..=15:                       (4-bit lengths: max 15)
    for sym in 0..count where lens[sym] == len:
        entry: (len, rev = reverse_bits(codeb) & ((1<<len)-1), value = sym)
        codeb += 1 << (32 - len)         (wrapping)
```

`huf_read`: scan entries **in build order**; first entry with
`peek(len) == rev` wins → `advance(len)`. If no entry matches → `None`
(the asm scans off the table into garbage — we fail closed). Then expand
the value: `v < 2` → result `v`; else `n = v - 1`; **if `n > 16` →
`None`** (the asm's word-sized mask cannot read more; real encoders cap
v at 16); result = `(1 << n) | read(n)`.

#### 4.C.4 Method 1 — unpack loop (`.rnc1209..`)

```text
read(2) discarded                        (stream starts with 2 pad bits)
while out.len() < unpacked:
    raw_t  = read_table();  dist_t = read_table();  len_t = read_table()
    ch_count = read(16);  if ch_count == 0: None    (asm would dbf-wrap)
    before = out.len()
    for i in 0..ch_count:
        if i > 0:                          # a match between literal runs
            dist = huf_read(dist_t) + 1
            len  = huf_read(len_t)  + 2
            guards: dist <= out.len(); out.len() + len <= unpacked
            len × forward byte copy: out.push(out[out.len() - dist])
                                       (overlap replicates; dist 1 = RLE)
        run = huf_read(raw_t)              # literal run, may be 0
        if run > 0:
            guards: p + run <= stream.len(); out.len() + run <= unpacked
            out.extend(stream[p .. p+run]); p += run; fix()
    if out.len() == before: None           (zero-progress chunk set)
```

(Structure per chunk set: literal run, then `(ch_count−1)` × [match,
literal run] — the asm's `bra .rnc120C` entry + `dbf d4` loop.)

#### 4.C.5 Method 2 — forward MSB-first recycled-sentinel bits (`RNC_2.S`)

Forward byte cursor shared by bit reloads and raw reads (Atomik's reader
mirrored forward). Init (`.rnc205`): load one byte `b`;
`reg = ((b << 2) & 0xFF) | 2` — the two top bits of the first byte are
**discarded pad**, and the init manufactures the sentinel; thereafter the
reader is: `carry = reg>>7; reg <<= 1; if reg == 0 { next = take_byte();
bit = next>>7; reg = (next<<1)|carry; return bit } return carry` —
identical shape to §4.A.2, forward. First byte ⇒ 6 data bits (bits 5..0);
each reloaded byte ⇒ 8. Output is written **forward**. The XOR key (`d4`)
is zero in this build — drop it entirely (keyed archives decode wrong and
fail the output CRC → `None`; ADR-19).

Main loop — 1 flag bit per event:

- flag `0` → **literal**: one raw byte → `out.push(byte)`.
- flag `1` → decode the prefix code below.

**Length prefix code** (`.rnc225..`; `x`/`y`/`z` are single bits):

| bits after the flag | meaning |
|---|---|
| `0, x, 0` | `len = 4 + x` (4 or 5) |
| `0, x, 1, z` | `v = (3 + x)*2 + z` → `v ∈ 6,7,8` ⇒ `len = v`; `v == 9` ⇒ **raw block** (below) |
| `1, 0` | `len = 2`, offset is **low-byte only** (high = 0) |
| `1, 1, 0` | `len = 3` |
| `1, 1, 1` + raw byte `b` | `b == 0` → **stream escape** (below); else `len = b + 8` (9..263) |

**Raw block** (`.rnc20E`): `v = 4 bits (MSB-first fold)`; copy
`4 * (v + 3)` bytes (12..72) **raw from the byte cursor** to the output;
no offset; back to the main loop.

**Stream escape** (`.rnc231`): read 1 bit: `1` → continue the main loop;
`0` → **end of stream**: require `out.len() == unpacked` (then the §4.C.1
output-CRC check runs), else `None`.

**Offset prefix code** (`.rnc216..`, for `len != 2`; produces the high
byte `hi`, then one raw byte `lo`; `dist = ((hi << 8) | lo) + 1`,
1..4096):

| bits | `hi` |
|---|---|
| `0` | 0 |
| `1, b, 0` with `b == 1` | 1 |
| `1, 0, 0, f` | 2 + f (2,3) |
| `1, b, 1, d, 1` | `(2b + d) \| 4` (4..7) |
| `1, b, 1, d, 0, f` | `((2b + d) \| 4) * 2 + f` (8..15) |

For `len == 2`: no prefix — `dist = lo + 1` (1..256). Copy is a forward
byte-by-byte loop (`out.push(out[out.len() - dist])`, overlap replicates;
the asm's dist-1 special case `.rnc21F` is just RLE — same result).
Guards on every copy/raw block: `dist <= out.len()`,
`out.len() + n <= unpacked`, raw reads in range.

#### 4.C.6 Refill past the stream end

`le16` (m1) reads out-of-range bytes as `0x00` (the asm reads whatever
memory follows; a real file never *consumes* those bits, and if a corrupt
one does, the output CRC catches it). Method-2 `take_byte` past the end is
`None` (its reads are always genuine consumption).

#### 4.C.7 What we deliberately drop

The **old RNC layout** (`RNC_1_1.S`): same `RNC\x01` magic but a 12-byte
header (no CRCs) and a backward byte-wise bit stream — incompatible and
indistinguishable by magic alone. Our `crc_pack` gate (§4.C.1) rejects old
files deterministically (their bytes at +12.. are stream data, not a CRC),
so they yield no candidate at all. Deferred; module doc comment + ADR-19.
Also dropped: the XOR key (§4.C.5), the in-place leeway machinery, and the
header `chunks` byte (both decoders loop on output position, as the asm
does).

```rust
use crate::ripper::registry::MAX_UNPACKED;

/// Backward reader; recycled-sentinel reload (§4.A.2 — NOT ICE's forced-1).
struct Stream<'a> { data: &'a [u8], pos: usize, reg: u8 }

impl<'a> Stream<'a> {
    fn new(data: &'a [u8]) -> Self { Self { data, pos: data.len(), reg: 0 } }
    fn take_byte(&mut self) -> Option<u8> {
        self.pos = self.pos.checked_sub(1)?;
        Some(self.data[self.pos])
    }
    fn bit(&mut self) -> Option<bool> {
        let carry = self.reg & 0x80 != 0;
        self.reg <<= 1;
        if self.reg == 0 {
            let next = self.take_byte()?;
            let bit = next & 0x80 != 0;
            self.reg = (next << 1) | u8::from(carry);
            return Some(bit);
        }
        Some(carry)
    }
    fn bits(&mut self, n: u32) -> Option<u32> { /* MSB-first fold, as ice_decode */ }
}

const BASES: [u32; 7] = [32, 96, 352, 864, 1888, 3936, 8032];
const XBITS: [u32; 8] = [0, 1, 3, 4, 5, 6, 7, 8];

/// Per-chunk parameters (§4.A.3 steps 1–4).
struct Chunk { spec: Option<(u8, [u8; 7])>, freq: Option<[u8; 16]>, d3: u32, size: usize }

fn chunk_header(s: &mut Stream) -> Option<Chunk>          // §4.A.3 1–4 (gates chunk==0 upstream)
fn take_length(s: &mut Stream, d3: u32) -> Option<u32>    // §4.A.4 length code
fn take_offset(s: &mut Stream, sel: usize, spec: Option<&(u8, [u8; 7])>) -> Option<usize> // §4.A.5
fn special_byte(s: &mut Stream, chunk: &Chunk, out: &[u8], write: usize) -> Option<u8> // §4.A.4 freq/delta
fn copy_match(out: &mut [u8], write: &mut usize, len: usize, val: usize) -> Option<()> // §4.A.5 copy
fn code_event(s: &mut Stream, chunk: &Chunk, out: &mut [u8], write: &mut usize) -> Option<()>

/// §4.A entry. `stream` = blob[12 .. 12+stream_len]. None = corrupt,
/// truncated, absurd, or picture-mode (pic byte != 0) — never a panic.
pub(crate) fn decrunch(stream: &[u8], unpacked_len: usize) -> Option<Vec<u8>> {
    if unpacked_len == 0 || unpacked_len > MAX_UNPACKED { return None; }
    let mut s = Stream::new(stream);
    if s.take_byte()? != 0 { return None; }        // picture mode: out of scope
    s.reg = s.take_byte()?;                        // raw init, no sentinel
    let mut out = vec![0u8; unpacked_len];
    let mut write = unpacked_len;
    loop {
        let chunk = chunk_header(&mut s)?;
        if chunk.size == 0 || chunk.size > write { return None; }
        let stop = write - chunk.size;
        while write > stop {
            if s.bit()? {
                code_event(&mut s, &chunk, &mut out, &mut write)?;
            } else {
                write -= 1;
                out[write] = s.take_byte()?;
            }
        }
        if write != stop { return None; }          // match overshot the chunk
        if s.pos == 0 { break; }
    }
    if write != 0 { return None; }
    Some(out)
}
```

`code_event` (≤30 lines): `take_length`; if 0 → `bit()`: 1 →
`special_byte` + write; 0 → `sel = bits(2)`, match len 2; else
`sel = bits(3)`, match len `len_code + 2`; then `take_offset` +
`copy_match`. `copy_match` guards `len <= *write` and `src < out.len()`
per byte, descending, with the P5-style comment that
`copy_within`/memmove would break RLE runs. Unit tests: §7.1.

```rust
    assert!(!payload.is_empty() && payload.len() <= 65_535);
    let mut script = vec![
        Ev::Bits(vec![0]), Ev::Bits(vec![0]),          // no spec table, no freq table
        Ev::Byte(0x00),                                 // d3
        Ev::Byte((payload.len() >> 8) as u8), Ev::Byte(payload.len() as u8),
    ];
    for &b in payload.iter().rev() {                    // output is backward:
        script.push(Ev::Bits(vec![0]));                 // last payload byte first
        script.push(Ev::Byte(b));
    }
    atomik_assemble(&script, payload.len() as u32)
}
```

#### 6.2.1 The pinned assembler

```rust
/// §4.B.2 serialization: one flat bit list in DECODER-consumption order
/// (multi-bit values MSB-first). n_longs = bits.len().div_ceil(32);
/// skip = 32*n_longs - bits.len(). The FIRST-consumed long is the LAST
/// data long in the file and holds bits[0..32-skip] at bit positions
/// skip..32 (bit index = LSB); each earlier file long holds the next 32
/// bits at positions 0..32. Blob = b"PP20" ++ eff ++ longs(BE) ++
/// be32((out_len << 8) | skip).
fn pp_assemble(bits: &[u8], out_len: u32) -> Vec<u8>       // eff fixed [9, 10, 12, 13]
fn msb(v: u32, n: u32) -> Vec<u8>                          // value → n bits MSB-first

/// Literal-only: flag 0, chunked 2-bit count (emit 3s, final chunk < 3),
/// then each byte as 8 bits — payload REVERSED (output is backward).
/// Literals are bit-packed at arbitrary bit offsets: no verbatim payload
/// bytes survive in the blob at all (strongest of the three).
fn pp_pack_literal(payload: &[u8]) -> Vec<u8> {
    let mut bits = vec![0u8];
    let mut d2 = payload.len() - 1;
    while d2 >= 3 { bits.extend(msb(3, 2)); d2 -= 3; }
    bits.extend(msb(d2 as u32, 2));
    for &b in payload.iter().rev() { bits.extend(msb(u32::from(b), 8)); }
    pp_assemble(&bits, payload.len() as u32)
}
```

```rust
/// Mirrors the reader: 16-bit LE cells; a raw run reclaims the (always
/// fully-unconsumed) lookahead cell's 2-byte slot and re-allocates one
/// after the run. Values are written LSB-first (peek semantics).
struct R1Writer { stream: Vec<u8>, cur: usize, f: u32, la: usize }
impl R1Writer {
    fn new() -> Self          // stream = vec![0;4]; cur=0; f=0; la=2
    fn bits(&mut self, v: u32, n: u32)
        // per bit j (LSB first): if f == 16 { cur = la; f = 0;
        //   la = stream.len(); push [0,0] }
        // if bit: stream[cur + f/8] |= 1 << (f%8);  f += 1
    fn raw(&mut self, data: &[u8])
        // assert la == stream.len()-2; truncate those 2 bytes; extend
        // with data; la = stream.len(); push [0,0]
}
fn r1_table(w: &mut R1Writer, lens: &[u32])   // bits(len(lens),5) + each bits(l,4)
```

**Method-1 PI1 packer** — literal runs of ≤16 raw bytes, one run per
chunk set (`ch_count = 1`, so no matches and the dist/len tables are
empty), which interrupts the payload in the blob every ≤16 bytes (< the
34-byte Degas header+palette → no depth-0 leak):

```rust
fn rnc1_pack_pi1(payload: &[u8]) -> Vec<u8> {   // returns the STREAM (no header)
    let mut w = R1Writer::new();
    w.bits(0, 2);                                // pad
    for run in payload.chunks(16) {
        match run.len() {
            16 => { r1_table(&mut w, &[0,0,0,0,0,1]);  // symbol 5: (1<<4)|extra4
                    r1_table(&mut w, &[]); r1_table(&mut w, &[]);
                    w.bits(1, 16); w.bits(0, 1); w.bits(0, 4); }
            2  => { r1_table(&mut w, &[0,0,1]);        // symbol 2: (1<<1)|extra1
                    r1_table(&mut w, &[]); r1_table(&mut w, &[]);
                    w.bits(1, 16); w.bits(0, 1); w.bits(0, 1); }
            n  => unreachable!("32034 = 2002*16 + 2, n = {n}"),
        }
        w.raw(run);
    }
    w.stream
}
```

**Method-2 writer**: consumption-order script exactly like Atomik's but

the init bit byte is unit 0 (loaded before any bit):

```rust
fn rnc2_assemble(script: &[Ev]) -> Vec<u8>       // same Ev enum, forward units
fn rnc2_pack_pi1(payload: &[u8]) -> Vec<u8> {    // returns the STREAM
    let mut script = Vec::new();
    for &b in payload {                          // m2 output is FORWARD
        script.push(Ev::Bits(vec![0]));

    script.push(Ev::Byte(0x00));                 // escape byte

}
```

```markdown
## 2026-07-XX — ADR-19: Atomik/PowerPacker/RNC depackers — scope cuts, end derivation, CRC gates, pinned synthetic fixtures

**Status:** accepted
**Context:** P9 triples the depacker roster (Atomik 3.5, PowerPacker PP20,
RNC ProPack), each ported from period 68k depack sources under ADR-14's
template (whole-buffer magic scan, first-success-wins, fail-closed None,
one plugin file + one registry line, pinned synthetic fixtures). Each
scheme forced a scope decision this ADR records.
**Decision:** (1) **Atomik: `ATM5` only.** The `ATOM` magic is shared by
at least Atomik 3.1, 3.3 and Thunder datafiles — the reference dispatcher
(NEW_DPAK's DEPACK.C) resolves it by asking the user, so magic-driven
depacking of `ATOM` would guess; deferred. Atomik's picture algorithm
(trailing count byte != 0: screens stored bitplane-transformed with an
offset table in the decoded output) is refused fail-closed — a wrongly
decoded picture is worse than none. The decoder is a semantic port of
depack35.s: backward stream, recycled-carry sentinel bit register (ICE's
reader with the reload sentinel recycled instead of forced 1 — the
fixture assembler therefore ZERO-fills bit bytes), per-chunk special-
offset/frequency tables and unary-threshold length coding, descending
overlap-replicating copies. (2) **PowerPacker: `PP20` only, derived end.**
PP20 carries no packed-length field (the format trusts the file size), so
a blob's end inside a RAM image is derived: try the trailing-zero-trimmed
end, then the buffer end (both aligned to the header, trailer-sanity
gated); the detector's extent is labelled estimated, the depacker
validates by decoding. Consequence: a PP20 blob followed by other
non-zero data in the same buffer is missed or mis-extended — accepted and
pinned by test; whole files and blobs in zeroed RAM (the dominant cases)
work. PX20 (XOR-encrypted, needs a passkey) and PPMT are not recognized.
An efficiency-table gate (each byte 4..=14) kills "PP20" text false
positives. (3) **RNC: standard 18-byte-header layout, methods 1 and 2,
CRC-16 gated both ways.** The header's packed-payload CRC-16/ARC is
checked at candidate time (detector and depacker — near-free, rejects
false positives and, deterministically, the incompatible OLD 12-byte
RNC\x01 layout of RNC_1_1.S, which is deferred); the output CRC is
checked after decode (the method-1 reference skips CRCs; the method-2
reference and dernc check them — we check uniformly). Method 1 is the
little-endian-word LSB-first bit stream with per-chunk canonical Huffman
tables and byte-aligned literal runs; method 2 is a forward MSB-first
prefix-code LZ with raw-block and end-of-stream escapes; the XOR key is
dropped (key 0 — keyed archives fail the output CRC and yield None).
(4) **Fixtures:** as ADR-14 — no committed binaries, no encoder ports;
per-packer consumption-order assemblers plus hand-traced vectors, all
mechanically verified against the spec before implementation. The
packed-PI1 recursion fixtures are literal-only where the encoding itself
interrupts or obscures the payload (Atomik/RNC: a flag-bit byte every <=8
literals, RNC m1: 16-byte runs; PP: literals are bit-packed and reversed)
so no contiguous Degas header survives at depth 0 — no P5-style split
needed. (5) **Detectors never decode** (uniform with pack-ice-region):
Atomik and RNC report header-exact extents; PP reports the derived
estimate rather than paying a validation decode.
**Alternatives considered:** guessing among ATOM variants by trying each
decoder (rejected: three incompatible schemes sharing a magic invites
silent wrong output; revisit with structural fingerprints); implementing
Atomik picture-mode now (rejected: needs the inverse bitplane transform
plus tail offset-table semantics, and no fixture path pins it); scanning
all aligned ends for PP20 (rejected: O(n) decode attempts per magic);
a decode-validating PP detector (rejected: breaks the cheap-detector
invariant; the depacker validates anyway); supporting the old RNC layout
behind the same magic (rejected: undetectable without decoding both ways;
the CRC gate cleanly selects the standard layout); skipping RNC method 2
as the task allowed (rejected: with the asm traced, method 2 is ~150
lines and method 1 is the harder one — both fit the budget).
**Consequences:** "add a packer" remains one plugin file + one registry
line (decode-helper siblings are pub(crate), not registration points).
The registry grows to 14 plugins; recursion depth/bomb guards are
untouched and now protect four depackers. Known misses are explicit and
tested: ATOM/PX20/PPMT/old-RNC blobs and non-zero-followed PP20 regions
yield nothing rather than wrong data.
```
