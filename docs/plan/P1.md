gated** boot (zero blind sleeps), `debug(cmd)` is a deterministic

parses into typed values pinned to real fixtures, addresses annotate against
the `memory_map.txt` dataset, and ten MCP tools expose it all with default
caps + pagination.

```rust
/// A live Hatari process + its control fifo and log tail. Owned by
/// `Session<Running>` / `Session<Paused>` (type-state `Data`, §5.2).
/// Dropping it kills Hatari (RAII last resort — §5.4 `stop` is the
/// graceful path).
#[derive(Debug)]
pub struct HatariProcess {
    child: Child,
    fifo: tokio::fs::File,          // write handle, opened once after boot gate
    log: crate::session::fifo::LogTail,
    config: HatariConfig,
}

impl HatariProcess {
    pub fn config(&self) -> &HatariConfig;
    pub fn pid(&self) -> Option<u32>;   // impl: self.child.id()

    /// Spawn + boot-gate. The ONLY constructor. Procedure (in order):
    /// 1. `tokio::fs::create_dir_all(&config.work_dir)`.
    /// 2. Remove stale `fifo_path()` and `log_path()` (`remove_file`,
    ///    ignore NotFound). Hatari CREATES the fifo — a pre-existing one
    ///    makes it error out.
    /// 3. Open `log_path()` for create/write (std File) and spawn:
    ///    Command::new(&config.hatari_path)
    ///      .args(["--machine", &config.machine])
    ///      .args(["--memsize", &config.memsize_mb.to_string()])
    ///      .arg("--tos").arg(&config.tos_path)
    ///      // if let Some(hd): .arg("--harddrive").arg(hd)
    ///      .args(["--fast-boot", on_off(config.fast_boot)])
    ///      .args(["--fast-forward", on_off(config.fast_forward)])
    ///      .args(["--confirm-quit", "off"])
    ///      .arg("--cmd-fifo").arg(config.fifo_path())
    ///      .stdout(log_file) .stderr(log_file_clone) .stdin(Stdio::null())
    ///      .kill_on_drop(true)
    ///    (debugger output goes to stdout/stderr → our log file; the two
    ///    Stdio handles are `try_clone`s of the same std File).
    /// 4. Wait-for-fifo: poll `fifo_path()` for FIFO existence every 100 ms
    ///    (`tokio::time::sleep` — this bounded poll is the one permitted
    ///    wait), up to `boot_timeout_ms`. On expiry: kill child, return
    ///    Error::Timeout { what: "hatari fifo creation".into(), waited_ms }.
    ///    Existence check: std::fs::metadata + FileTypeExt::is_fifo
    ///    (std::os::unix::fs::FileTypeExt).
    /// 5. Open the fifo for WRITE (tokio::fs::OpenOptions::new().write(true)
    ///    .open(..)) — Hatari is already the reader, so this does not block
    ///    indefinitely; guard it with tokio::time::timeout(boot budget left).
    /// 6. Construct LogTail over `log_path()` (§5.6), cursor at 0.
    /// 7. Boot gate = one sentinel round-trip: `self.debug("evaluate pc")`
    ///    (§5.6) with `boot_timeout_ms` as the timeout. Success proves the
    ///    control plane is live — THIS is the Booting→Running transition;
    ///    there is no sleep-based "wait for TOS".
    /// On ANY failure after step 3: best-effort `child.start_kill()`, then
    /// return the error (the child is also `kill_on_drop`).
    pub async fn spawn(config: HatariConfig) -> Result<Self>;

    /// Sentinel-synced debugger command (delegates to fifo::debug, §5.6),
    /// using config.sentinel_timeout_ms unless `timeout_ms` overrides it.
    pub async fn debug(&mut self, cmd: &str) -> Result<String>;
    pub async fn debug_with_timeout(&mut self, cmd: &str, timeout_ms: u64) -> Result<String>;

    /// Raw wrapper-command writers (no sentinel — see §5.6 rationale).
    pub async fn write_wrapper(&mut self, line: &str) -> Result<()>;

    /// Graceful kill: write "hatari-shortcut quit\n" (ignore write errors),
    /// then wait up to 2 s for exit (tokio::time::timeout(2s, child.wait())),
    /// else child.kill().await (SIGKILL) + wait. Log failures via
    /// tracing::warn!; never return Err — a session must always be
    /// stoppable (P0 §7.2 contract).
    pub async fn shutdown(mut self);
}

fn on_off(b: bool) -> &'static str; // impl: if b { "on" } else { "off" }
```

`Drop for HatariProcess` needs **no manual impl**: `kill_on_drop(true)`
(step 3) makes tokio reap the child if `shutdown` was never called. Do not
write a custom `Drop`.

### 5.5 `src/session/memory.rs` — MemImage acquisition (SPIKE, decided procedure)

The open question from BRAINSTORM ("whole-RAM dump or assembled `m` dumps?")
is resolved by a **fixed decision procedure**, not engineering judgment.
`strings /usr/bin/hatari` already shows `savebin` exists ("save memory to a
file"), so branch (a) is expected to win — but run the procedure and record
the outcome as ADR-9 (§12) either way.

**Decision procedure** (do this once, manually or as a throwaway `#[ignore]`
test, before wiring `acquire`):

1. Start the MJJ session (DEBUG.md invocation). Send via sentinel:
   `savebin /tmp/shiraz-mcp/spike-ram.bin 0 $100000`
   (syntax `savebin <file> <address> <length>`; if it errors, try
   `savebin /tmp/shiraz-mcp/spike-ram.bin $0 $100000` — `// confirm syntax
   with `hatari-debug help savebin` output in the log`).
2. **Accept branch (a)** iff: the sentinel round-trip succeeds AND
   `/tmp/shiraz-mcp/spike-ram.bin` exists with size exactly `0x100000` AND
   the file is not all-zero (TOS variables at `$400..` guarantee nonzero
   bytes in a booted machine).
3. Otherwise **fall back to branch (b)**.

**Branch (a) — `savebin` (expected):**

**Branch (b) — assembled `m` dumps (fallback, fully designed):**

### 5.6 `src/session/fifo.rs` — the sentinel protocol (load-bearing, ADR-7)

Exact constants (contractual — tests in §10.1 assert against them):

```rust
/// What we WRITE after every command (uppercase, as typed).
pub(crate) const SENTINEL_CMD: &str = "hatari-debug evaluate $DEADBEEF";
/// What Hatari ECHOES when the sentinel evaluates. Matched against the
/// RESULT line, not the `> evaluate $DEADBEEF` echo line: Hatari prints
/// evaluate results as `= %<bin> (bin), #<dec> (dec), $<lowercase-hex> (hex)`
/// (fixture line: `= %1101110010001000 (bin), #56456 (dec), $dc88 (hex)`),
/// so the marker's result line is uniquely:
pub(crate) const SENTINEL_ECHO: &str = "#3735928559 (dec), $deadbeef (hex)";
```

A log line "completes" the sentinel iff it starts with `"= %"` (after
trimming) AND contains `SENTINEL_ECHO`. The `> hatari-debug …` /
`> evaluate $DEADBEEF` command echoes are uppercase and lack the `= %`
prefix, so they can never false-match. (Memory-dump ASCII gutters print `.`
for non-printables and never start with `= %` — no collision path.)

```rust
use std::path::PathBuf;
use crate::error::{Error, Result};

/// Tails the Hatari log file by polling (no inotify dependency): remembers
/// a byte cursor, reads only NEW bytes each pass. The cursor is what makes
/// a FIXED marker safe across repeated calls — old sentinel echoes are
/// behind the cursor and can never satisfy a new command.
#[derive(Debug)]
pub struct LogTail {
    path: PathBuf,
    cursor: u64,
    pending: String,   // carry-over for a partial last line between polls
}

impl LogTail {
    pub fn new(path: PathBuf) -> Self;   // cursor 0, empty pending

    /// Read from the cursor until a line satisfying `is_marker` appears.
    /// Poll cadence: read-new-bytes, scan complete lines, else
    /// tokio::time::sleep(25 ms); overall budget `timeout_ms`, enforced
    /// with an Instant deadline (NOT per-iteration timeouts). On expiry:
    /// Error::Timeout { what: what.to_string(), waited_ms: timeout_ms }.
    /// Returns all COMPLETE lines read after the starting cursor,
    /// EXCLUDING the marker line itself. Advances the cursor past the
    /// marker line.
    pub async fn read_until(
        &mut self,
        is_marker: impl Fn(&str) -> bool,
        what: &str,
        timeout_ms: u64,
    ) -> Result<Vec<String>>;
    // impl: tokio::fs::File::open + seek to cursor each poll (reopen per
    //       poll is fine at 25 ms cadence and dodges rotation/truncation
    //       edge cases); read_to_string of the tail; split off complete
    //       lines ('\n'-terminated), keep the remainder in `pending`.
}

/// The debug(cmd) primitive (ADR-7). Exact write sequence to the fifo:
///   "hatari-debug <cmd>\n"
///   "hatari-debug evaluate $DEADBEEF\n"
/// then LogTail::read_until(sentinel-match, what = format!("sentinel after {cmd}"),
/// timeout_ms). Post-filter the returned lines before joining:
///   - drop any line starting with "> "            (command echoes)
///   - drop lines that are empty after trim
/// Return the remaining lines joined with '\n'.
pub async fn debug(
    fifo: &mut tokio::fs::File,
    log: &mut LogTail,
    cmd: &str,
    timeout_ms: u64,
) -> Result<String>;

```rust
/// Parse `cpureg` output. Fixture shape (lines, after echo-filtering):
///   "  D0 03FF0052   D1 00035CF0   D2 C0000000   D3 07FF040F "
///   "  D4 ...  D7 ..."           (same shape, D4-D7)
///   "  A0 00FF8A00   A1 ...  A3 ..."
///   "  A4 ...  A7 ..."
///   "USP  000F7FEE ISP  000F7FE2 "
///   "T=00 S=1 M=0 X=0 N=1 Z=0 V=0 C=0 IMASK=6 STP=0"
///   "Prefetch 2f00 (MOVE) 4e75 (RTS) Chip latch 00000000"
///   "0000dc74 2f00                     move.l d0,-(a7) [03ff0052]"
///   "Next PC: 0000dc76"
/// Algorithm: scan whitespace-split tokens of every line for NAME,VALUE
/// pairs where NAME ∈ {D0..D7, A0..A7, USP, ISP} and VALUE is 8 hex
/// digits. Parse the T=/S=/X=/N=/Z=/V=/C=/IMASK= line by splitting on
/// whitespace then '='. PC: the line immediately BEFORE the line starting
/// with "Next PC:" — its first token, 8 hex digits (fixture: 0000dc74).
/// All 16 D/A registers, USP, ISP, the flag line, and the PC line are
/// REQUIRED; anything missing → Error::Parse { context: "cpureg", .. }.
pub fn parse_cpureg(out: &str) -> Result<Registers>;

/// Parse `evaluate` output. Fixture line:
///   "= %1101110010001000 (bin), #56456 (dec), $dc88 (hex)"
/// Find the line starting with "= %"; extract the token after '#' up to
/// ' ' → u32 decimal (the decimal field avoids hex-width ambiguity).
pub fn parse_evaluate(out: &str) -> Result<u32>;

/// Parse `m` memdump output into bytes. Fixture line:
///   "000F8000: 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00   ................"
/// For every line containing ": ": take the part after the first ": ",
/// take the first 47 chars (16 two-digit hex bytes + 15 separating
/// spaces) — this excludes the ASCII gutter even when the gutter contains
/// hex-looking text — then parse whitespace-split hex pairs. Lines
/// without ": " are skipped (headers/echo leakage). Zero parsed bytes
/// overall → Error::Parse { context: "memdump", .. }.
pub fn parse_memdump(out: &str) -> Result<Vec<u8>>;

/// Parse `symbols prg`. Fixture (error case, lines 7-8 of the fixture):
///   "ERROR: symbol table missing from the program!"
/// Success case (per DEBUG.md — not in the fixture; // confirm when a
/// symbol-bearing PRG is available):
///   "Loaded 184 symbols (40 TEXT) from '...'."
/// Any line starting "Loaded " → parse the two integers → SymbolLoad::Loaded.
/// Any line containing "symbol table missing" → SymbolLoad::NoSymbols.
/// Neither → Error::Parse { context: "symbols prg", .. }.
pub fn parse_symbols(out: &str) -> Result<SymbolLoad>;

/// Parse `screenshot` output. Fixture line:
///   "Screen dump to '/tmp/hatari_shot.png' succeeded"
/// A line containing "Screen dump to" AND "succeeded" → Ok(()); else
/// Error::Parse { context: "screenshot", input: out.into() }.
pub fn parse_screenshot(out: &str) -> Result<()>;
```

### 7.2 `src/analyze/map.rs` + `src/analyze/memory_map.txt` — the dataset

**Dataset:** copy
`$HOME/projects/ShirazMCP/.claude/skills/atari-st-hardware-map/reference/memory_map.txt`
**verbatim** to `src/analyze/memory_map.txt` (1465 lines; committed — the
skill directory is not a build input). Add a one-line provenance comment in
`map.rs` (the txt itself is not modified). Entry shape (real lines):

```
$FF8240|word |Video palette register 0              Lowercase = LSB|R/W
$FF8800|byte |Read data/Register select                            |R/W
$000004|Reset : Initial PC                                         |SP
```

i.e. `$ADDR|<size?> |<description>|<access>` — the size field is absent on
low-memory/vector entries (3 `|`-fields instead of 4). Section headers are
`#`-fenced lines (`########CPU Exception Vectors  ######`).

**Loading decision (pinned):** `include_str!("memory_map.txt")` at compile
time, parsed **once at runtime** into a sorted index behind
`std::sync::LazyLock`. No build script (nothing to generate), no runtime
file I/O (no path fragility), no `const` parsing (format is too loose to be
worth a const parser). This is the recorded choice — do not revisit.

```rust
use std::sync::LazyLock;

/// One dataset row. `group` is the nearest preceding section header
/// (trimmed of '#' fencing and whitespace), e.g. "CPU Exception Vectors".
#[derive(Debug, Clone, Copy)]
pub struct MapEntry {
    pub addr: u32,                  // 24-bit, as listed
    pub group: &'static str,
    pub desc: &'static str,         // description field, trim_end()ed
                                    // (internal runs of spaces kept as-is)
    pub size: Option<&'static str>, // "word"/"byte"/... when present
}

static MAP: LazyLock<Vec<MapEntry>> = LazyLock::new(parse_dataset);

/// Parse rules (exactly these):
/// - A line whose trimmed form starts with '#': strip all '#' and trim →
///   if non-empty, it becomes the current `group`.
/// - A line starting with '$': split on '|'. Field 0 (minus '$') parses as
///   hex u32 — on parse failure SKIP the line (some rows are `$xxxx-$yyyy`
///   ranges or prose; P1 indexes exact rows only, the range cases we need
///   are covered by the OVERRIDES table in §7.3). With 4+ fields: size =
///   field 1 trimmed (None if empty), desc = field 2; with 3 fields:
///   size = None, desc = field 1. desc = trim_end().
/// - Everything else: skip.
/// Post: sort by addr; on duplicate addrs keep the FIRST occurrence.
fn parse_dataset() -> Vec<MapEntry>;

/// Exact-address lookup (binary search). `addr` must already be 24-bit-
/// masked by the caller.
pub fn lookup(addr: u32) -> Option<MapEntry>;

/// Word-register fallback: if `addr` is odd and `addr - 1` hits an entry
/// with size == Some("word"), return that entry (callers label it as the
/// low byte). Used by annotate(); kept here so it's unit-testable.
pub fn lookup_word_base(addr: u32) -> Option<MapEntry>;
```

### 7.3 `src/analyze/annotate.rs`

/// P1 tools pass None (no write-stream tracking yet — the PSG-aware path
/// is exercised by unit tests and by P2's disasm annotations).

/// ARCHITECTURE.md shape. `register` = component/group ("Shifter", "PSG",
/// or the dataset section name); `detail` = human description.
/// Tool JSON renders it as label = "{register} — {detail}" (§8.4).

    pub addr: Addr,
    pub register: &'static str,
    pub detail: String,
}

/// Annotate a bus address. Lookup order (first hit wins):
///  0. Mask: a = addr.raw() & 0x00FF_FFFF (68000 24-bit bus — $FFFF8240
///     and $FF8240 are the same register).
///  1. PSG special-case (BEFORE the dataset, so select-awareness wins):
///     a == 0xFF8800 → { register: "PSG", detail: "register select / read data" }
///     a == 0xFF8802 →
///       psg = Some(PsgSelect(n)) → { "PSG", format!("write data → register {n} ({})", PSG_REG_NAMES[n & 0xF]) }
///       psg = None               → { "PSG", "write data".to_string() }
///  2. OVERRIDES ranges (computed-index annotations):
///     0xFF8240..=0xFF825F → { register: "Shifter",
///                             detail: format!("palette register {}", (a - 0xFF8240) / 2) }
///     (odd addresses fall in the same slot: (a-base)/2 truncates — a byte
///     access to $FF8241 is still "palette register 0".)
///  3. map::lookup(a) → { register: entry.group, detail: entry.desc.to_string() }
///  4. map::lookup_word_base(a) → { register: entry.group,
///                                  detail: format!("{} (low byte)", entry.desc) }
///  5. None.
pub fn annotate(addr: Addr, psg: Option<PsgSelect>) -> Option<Annotation>;

/// YM2149 register names, index 0..=15 (exact strings — tests assert them):
pub const PSG_REG_NAMES: [&str; 16] = [

    "channel C period fine", "channel C period coarse",
    "noise period", "mixer control",
    "channel A level", "channel B level", "channel C level",
    "envelope period fine", "envelope period coarse", "envelope shape",
    "I/O port A", "I/O port B",
];
```

//       search_memory do the same for their parse failures);
//       count = a.count.unwrap_or(READ_DEFAULT).min(READ_MAX);
//       debug::read_bytes(proc, addr, count as usize) → hex-encode;
//       next_addr = Addr::new(addr.raw() + count) (Display).

#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct WriteMemoryArgs {
    pub addr: String,
    /// Even-length hex string, max 256 bytes ("0badf00d").
    pub bytes_hex: String,
}
#[derive(Debug, serde::Serialize, schemars::JsonSchema)]
pub struct WriteMemoryOutput { pub addr: String, pub written: u32 }

#[tool(name = "write_memory", description = "Write bytes into emulator \
memory (max 256 per call). Bytes as an even-length hex string.")]
pub async fn write_memory(&self, Parameters(a): Parameters<WriteMemoryArgs>)
    -> Result<Json<WriteMemoryOutput>, McpError>;
// impl: decode hex (reject odd length / non-hex / > WRITE_MAX via
//       invalid_params); debug::write_bytes(proc, addr, &bytes).

#[derive(Debug, serde::Deserialize, schemars::JsonSchema)]
pub struct SearchMemoryArgs {
    /// Hex byte pattern ("4e75"). Exactly one of pattern_hex/pattern_ascii.
    pub pattern_hex: Option<String>,
    /// ASCII pattern, matched as raw bytes.
    pub pattern_ascii: Option<String>,
    /// Search window start (default $0).
    pub start: Option<String>,
    /// Search window end, exclusive (default: top of RAM).
    pub end: Option<String>,
    /// Max hits returned (default 16, max 64).
    pub limit: Option<u32>,
    /// Skip the first N hits (pagination: offset += limit).
    pub offset: Option<u32>,
}
#[derive(Debug, serde::Serialize, schemars::JsonSchema)]
pub struct SearchHit {
    pub addr: String,
    /// HIT_CONTEXT bytes starting at the hit, lowercase hex.
    pub context_hex: String,
    pub annotations: Vec<AnnotationOut>,
}
#[derive(Debug, serde::Serialize, schemars::JsonSchema)]
pub struct SearchMemoryOutput {
    pub hits: Vec<SearchHit>,
    pub offset: u32,
    /// More hits exist beyond offset+hits.len() — call again with a larger
    /// offset.
    pub has_more: bool,
}

#[tool(name = "search_memory", description = "Search all emulator RAM for a \
byte or ASCII pattern (server-side scan over a snapshot — the agent only \
sees compact hits: address + 16 context bytes + annotations). Default 16 \
hits; page with offset.")]
pub async fn search_memory(&self, Parameters(a): Parameters<SearchMemoryArgs>)
    -> Result<Json<SearchMemoryOutput>, McpError>;
// impl: validate exactly-one pattern (invalid_params otherwise); needle =
//       hex-decode or as_bytes; empty needle → invalid_params.
//       mem = session::memory::acquire(proc).await (ADR-5: the server owns
//       the megabytes — ONE snapshot, then a pure in-process scan; never a
//       per-address debugger loop).
//       Window = [start.unwrap_or($0), end.unwrap_or(ram top)) clamped to
//       the image. Scan with memchr::memmem::find_iter(window, needle);
//       skip `offset` hits, take `limit`, probe one extra for has_more.
//       Hit addr = window base + match offset (Addr). context_hex = the
//       HIT_CONTEXT bytes at the hit (clamped at image end). Annotations
//       via annotations_for(hit_addr, needle.len()).
```

## 12. ADR-9 — append to `decisions.md` (fill the ONE bracketed outcome)

```markdown
## 2026-07-XX — ADR-9: MemImage acquisition via [savebin whole-RAM dump | assembled `m` memdumps]

**Status:** accepted
**Context:** The ripper (ADR-2, ADR-5) operates on a `MemImage` snapshot of
all ST RAM (≤ 4 MB). BRAINSTORM left open whether Hatari can dump RAM to a
file in one command or whether we must assemble it from ranged `m` memdumps
over the sentinel fifo. Spike procedure and both designs: docs/plan/P1.md §5.5.
**Decision:** [Branch (a): Hatari 2.4.1's `savebin <file> <addr> <len>`
debugger command dumps the full range to a file in one sentinel round-trip;
`acquire()` sends it, reads the file, and validates the exact length.
| Branch (b): `savebin` failed the §5.5 criteria (<state exactly how>);
`acquire()` assembles 1024-byte `m` dumps (~1024 round-trips per MiB).]
**Alternatives considered:** [the losing branch, with the observed failure
or the measured cost]; Hatari memory-snapshot files (`--memstate`) — rejected:
snapshot format is internal/versioned, not a raw RAM image.
**Consequences:** [(a): acquisition is one round-trip + one file read
(~milliseconds for 1 MiB); the RAM dump file under work_dir doubles as
filesystem intermediate state (ADR-5). | (b): acquisition is O(RAM/1 KiB)
round-trips; callers should prefer Paused and cache the image per pause.]
The losing branch's code is NOT kept behind a flag — this ADR records it.
```
