```rust
//! ST planar-graphics decode (P4): interleaved bitplanes → chunky → RGBA,
//! ST/STE palette words → 8-bit color. Pure over byte slices; shared by the
//! degas/neochrome plugins and the `view_memory_as_screen` tool.
//! Layout reference: skill `atari-st-bitplanes`;
//! Atari_ST_Sources/ASM/Lineout/Stone Tower/src/STLOWC2P.S (c2p, reversed).

use std::io::Cursor;

use image::RgbaImage;

use crate::error::{Error, Result};

/// Every ST screen is exactly 32000 bytes, all three resolutions.
pub const SCREEN_BYTES: usize = 32000;

/// The three ST video modes. `Med` is the file/register value 1.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ScreenRes {
    Low,  // 320×200, 16 colors, 4 planes
    Med,  // 640×200,  4 colors, 2 planes
    High, // 640×400, mono,      1 plane
}

impl ScreenRes {
    /// Degas/NEO resolution word and the `$FF8260` register value.
    pub const fn from_word(w: u16) -> Option<Self> { /* 0|1|2 → Some, else None */ }
    pub const fn width(self) -> u32 { /* 320 | 640 | 640 */ }
    pub const fn height(self) -> u32 { /* 200 | 200 | 400 */ }
    pub const fn planes(self) -> usize { /* 4 | 2 | 1 */ }
    /// width/8 × planes: 160 | 160 | 80. bytes_per_line × height == 32000.
    pub const fn bytes_per_line(self) -> usize { /* 160 | 160 | 80 */ }
    pub const fn name(self) -> &'static str { /* "low" | "medium" | "high" */ }
}

/// 16 decoded RGBA colors. Construct with `from_words`; index with `color`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Palette {
    colors: [[u8; 4]; 16],
}
```

**Palette word decode — the pinned math.** A palette word `w` (big-endian on
disk/in RAM) has nibbles `r = (w >> 8) & 0xF`, `g = (w >> 4) & 0xF`,
`b = w & 0xF`; bits 12–15 unused.

- **ST/STE auto-detection is per-palette, not per-word:** the palette is STE
  iff ANY of the 16 words has a nibble bit 3 set —
  `words.iter().any(|w| w & 0x0888 != 0)`. (An ST program can only write
  0–7 per nibble; bit 3 anywhere proves STE encoding.)
- **ST (3-bit):** channel value `v = n & 7`, 8-bit output `v * 255 / 7`
  (integer division: 0,36,72,109,145,182,218,255 for v = 0..=7).
- **STE (4-bit, bit-rotated — the LSB is stored in the nibble's bit 3):**
  `v4 = ((n & 7) << 1) | (n >> 3)`, 8-bit output `v4 * 17` (0..=255).
- Alpha is always 255.

```rust
impl Palette {
    pub fn from_words(words: &[u16; 16]) -> Self {
        let ste = words.iter().any(|w| w & 0x0888 != 0);
        Self { colors: words.map(|w| decode_word(w, ste)) }
    }

    /// `index` is masked to 0..=15 — never panics.
    pub fn color(&self, index: u8) -> [u8; 4] {
        self.colors[(index & 15) as usize]
    }
}

fn decode_word(w: u16, ste: bool) -> [u8; 4] {
    let chan = |n: u16| -> u8 {
        if ste {
            (((((n & 7) << 1) | (n >> 3)) * 17) & 0xFF) as u8
        } else {
            ((n & 7) * 255 / 7) as u8
        }
    };
    [chan((w >> 8) & 0xF), chan((w >> 4) & 0xF), chan(w & 0xF), 255]
}
```

**Palette helpers used by both plugins (detection):**

```rust
/// Read 16 big-endian words from a 32-byte slice. None iff bytes.len() < 32.
pub fn palette_words(bytes: &[u8]) -> Option<[u16; 16]> {
    let b = bytes.get(..32)?;
    let mut out = [0u16; 16];
    for (i, w) in out.iter_mut().enumerate() {
        *w = u16::from_be_bytes([b[2 * i], b[2 * i + 1]]);
    }
    Some(out)
}

/// Detection heuristic shared by degas/neochrome: every word's unused upper
/// nibble is clear AND at least 4 distinct values appear. The distinctness
/// gate is what stops zero-filled RAM (res word 0 + 32 zero bytes) from
/// matching at every offset (ADR-12).
pub fn plausible_palette(words: &[u16; 16]) -> bool {
    if words.iter().any(|w| w & 0xF000 != 0) {
        return false;
    }
    let mut sorted = *words;
    sorted.sort_unstable();
    let distinct = 1 + sorted.windows(2).filter(|p| p[0] != p[1]).count();
    distinct >= 4
}

/// (amended per ADR-13) NEO header signature at `o`: flag word 0, valid res
/// word, plausible palette at +4, AND width/height == 320/200 at +58/+60
/// (real header fields, NEO_IO.C authority). Lives here — NOT in
/// neochrome.rs — because degas.rs also consults it as a negative guard;
/// plugins never import each other.
pub fn neo_header_at(bytes: &[u8], o: usize) -> bool {
    let word = |off: usize| bytes.get(off..off + 2).map(|b| u16::from_be_bytes([b[0], b[1]]));
    word(o) == Some(0)
        && word(o + 2).is_some_and(|w| ScreenRes::from_word(w).is_some())
        && bytes
            .get(o + 4..o + 36)
            .and_then(palette_words)
            .is_some_and(|ws| plausible_palette(&ws))
        && word(o + 58) == Some(320)
        && word(o + 60) == Some(200)
}
```

**Planar decode — the pinned algorithm.** Pixels are word-interleaved: each
horizontal group of 16 pixels is `planes` consecutive big-endian words (one
per plane), then the next group follows. Pixel `p` (0 = leftmost in group)
uses bit `15 - p` of each plane word; plane `pl` contributes bit `pl` of the
color index (plane 0 = LSB).

```rust
/// Decode `SCREEN_BYTES` of interleaved planes into RGBA. Uses the FIRST
/// 32000 bytes of `data`; Err (Parse) if shorter — callers pass exact slices.
pub fn decode_planar(data: &[u8], res: ScreenRes, pal: &Palette) -> Result<RgbaImage> {
    let Some(data) = data.get(..SCREEN_BYTES) else {
        return Err(Error::Parse {
            context: "planar decode".to_string(),
            input: format!("{} bytes, need {SCREEN_BYTES}", data.len()),
        });
    };
    let (planes, bpl) = (res.planes(), res.bytes_per_line());
    let mut img = RgbaImage::new(res.width(), res.height());
    for y in 0..res.height() {
        let line = &data[y as usize * bpl..][..bpl];
        for group in 0..res.width() / 16 {
            let words = group_words(line, group as usize, planes);
            for p in 0..16u32 {
                let mut idx = 0u8;
                for (pl, w) in words[..planes].iter().enumerate() {
                    idx |= (((w >> (15 - p)) & 1) as u8) << pl;
                }
                img.put_pixel(group * 16 + p, y, image::Rgba(pal.color(idx)));
            }
        }
    }
    Ok(img)
}

fn group_words(line: &[u8], group: usize, planes: usize) -> [u16; 4] {
    let base = group * planes * 2;
    let mut out = [0u16; 4];
    for (pl, w) in out[..planes].iter_mut().enumerate() {
        *w = u16::from_be_bytes([line[base + 2 * pl], line[base + 2 * pl + 1]]);
    }
    out
}
```

(The direct indexing is provably in-bounds: `line.len() == bpl` and
`(width/16) * planes * 2 == bpl` for all three resolutions. Do not add
`.get()` noise here; clippy's indexing lint is not denied.)

### 5.4 `src/ripper/plugins/degas.rs` — NEW: Degas / Degas Elite

Byte layout (skill `atari-st-degas`):

- **PI1/PI2/PI3 (uncompressed), total 32034 bytes:** word 0 = resolution
  (0=low/PI1, 1=med/PI2, 2=high/PI3); bytes 2..34 = 16 palette words; bytes
  34..32034 = 32000 bytes of standard interleaved planes.
- **PC1/PC2/PC3 (Degas Elite RLE), total 34 + compressed:** word 0 =
  resolution **with bit 15 set** (`$8000`/`$8001`/`$8002`); bytes 2..34 =
  palette; bytes 34.. = RLE stream that decodes to exactly 32000 bytes.

```rust

//! Layouts: skill `atari-st-degas`. RLE + de-interleave semantics derived

//! DegasPutByte) — cited for semantics, not ported.
```

**5.4.1 Detection (`scan`).** Scan **even offsets only** (68000 code loads
word-aligned data; halves the work — document this in a comment). At each
offset try PI then PC; on a hit, push the finding and jump past it (rounded
up to even) — overlapping duplicates of the same picture are agent noise.

```rust
impl RipPlugin for Degas {
    fn id(&self) -> PluginId { PluginId::new("degas") }
    fn kind(&self) -> RipKind { RipKind::Picture }
    fn describe(&self) -> &'static str {
        "Degas PI1/PI2/PI3 and Degas Elite PC1/PC2/PC3 pictures"
    }
    fn scan(&self, mem: &MemImage) -> Vec<Finding> {
        let bytes = mem.bytes();
        let mut out = Vec::new();
        let mut o = 0usize;
        while o + 34 <= bytes.len() {
            match try_pi(bytes, o).or_else(|| try_pc(bytes, o)) {
                Some(f) => {
                    let len = f.len;
                    out.push(f);
                    o += (len + 1) & !1; // skip the artifact, keep even
                }
                None => o += 2,
            }
        }
        out
    }
    fn render_png(&self, bytes: &[u8]) -> Option<Vec<u8>> { render(bytes) }
}
```

Helpers (all private; `be16(bytes, o) -> Option<u16>` reads a big-endian word
via `bytes.get(o..o + 2)`):

```rust
fn try_pi(bytes: &[u8], o: usize) -> Option<Finding> {
    let w = be16(bytes, o)?;
    let res = ScreenRes::from_word(w)?;              // rejects w > 2
    if o + PI_TOTAL > bytes.len() {
        return None;
    }
    let words = palette_words(&bytes[o + 2..o + 34])?;
    if !plausible_palette(&words) {
        return None;
    }
    // ADR-13: Degas defers to NeoChrome. Every NEO aliases as a PI header at
    // its own offset (flag word 0 = valid low-res word) and at +2 (res word
    // 0 + full palette); the far more specific NEO signature wins the tie.
    if neo_header_at(bytes, o) || (o >= 2 && neo_header_at(bytes, o - 2)) {
        return None;
    }
    Some(Finding::new(
        PluginId::new("degas"),
        RipKind::Picture,
        Offset::new(o),
        PI_TOTAL,
        format!("Degas PI{} {}x{} picture ({})", w + 1, res.width(), res.height(), res.name()),
    ))
}

fn try_pc(bytes: &[u8], o: usize) -> Option<Finding> {
    let w = be16(bytes, o)?;
    if w & 0x8000 == 0 {
        return None;
    }
    let res = ScreenRes::from_word(w & 0x7FFF)?;
    let words = palette_words(bytes.get(o + 2..o + 34)?)?;
    if !plausible_palette(&words) {
        return None;
    }
    let end = (o + 34 + MAX_PC_INPUT).min(bytes.len());
    let (_, consumed) = rle_decode(&bytes[o + 34..end])?; // decode proves it
    Some(Finding::new(
        PluginId::new("degas"),
        RipKind::Picture,
        Offset::new(o),
        34 + consumed,
        format!("Degas PC{} {}x{} RLE picture, {consumed} bytes compressed ({})",
                (w & 0x7FFF) + 1, res.width(), res.height(), res.name()),
    ))
}
```

**5.4.2 The RLE — pinned control-byte semantics (from `DEGAS.C::DegasGet`).**
Read one control byte `c`:

- `c` in `0x00..=0x7F`: **literal** — copy the next `c + 1` input bytes.
- `c` in `0x81..=0xFF`: **run** — repeat the next single input byte
  `257 - c` times (2..=128 copies).
- `c == 0x80`: **no-op** — consume the control byte, emit nothing
  (DEGAS.C's `prefix` falls through both branches).

Decode until the output reaches exactly 32000 bytes. Any block that would
exceed 32000, and any read past the end of input, means "not PC data" →
`None` (never an error: this runs inside detection). Return the output AND
the number of input bytes consumed — the finding's `len` needs it. The RLE
stream is continuous: runs/literals MAY cross scanline boundaries (DEGAS.C
streams byte-by-byte through `DegasPutByte`; encoders that restart per line
are a strict subset).

```rust
/// PackBits-style Degas Elite RLE. Some((linear, consumed)) on success.
fn rle_decode(input: &[u8]) -> Option<(Vec<u8>, usize)> {
    let mut out = Vec::with_capacity(SCREEN_BYTES);
    let mut i = 0usize;
    while out.len() < SCREEN_BYTES {
        let c = *input.get(i)?;
        i += 1;
        if c <= 0x7F {
            let n = c as usize + 1;
            let lit = input.get(i..i + n)?;
            if out.len() + n > SCREEN_BYTES {
                return None;
            }
            out.extend_from_slice(lit);
            i += n;
        } else if c >= 0x81 {
            let n = 257 - c as usize;
            let b = *input.get(i)?;
            i += 1;
            if out.len() + n > SCREEN_BYTES {
                return None;
            }
            out.resize(out.len() + n, b);
        }
    }
    Some((out, i))
}
```

**5.4.3 The de-interleave — pinned (THE easy-to-get-wrong part).** The
decompressed 32000 bytes are NOT the interleaved screen. Degas Elite stores
them **per scanline, one whole plane-line at a time**: for each row `r`
(top to bottom), all `width/8` bytes of plane 0's row, then plane 1's row, …
then plane `P-1`'s row; then the next row. This is exactly what
`DEGAS.C::DegasPutByte` implements in reverse: it writes decompressed byte
`k` of plane `p`, row `r` to interleaved offset
`r*bpl + (k/2)*2*P + p*2 + (k & 1)` (trace: `bytix` starts at `p*2`, writes
2 bytes, then skips `2*P - 2` to the same plane's next word; after `width/8`
bytes it advances to the next plane, after the last plane to the next row).

```rust
/// Linear (per-row, plane-by-plane) → standard word-interleaved screen.
/// linear MUST be exactly SCREEN_BYTES (guaranteed by rle_decode).
fn reinterleave(linear: &[u8], res: ScreenRes) -> Vec<u8> {
    let (planes, bpl) = (res.planes(), res.bytes_per_line());
    let plane_line = bpl / planes; // bytes of one plane's row: 40 | 80 | 80
    let mut out = vec![0u8; SCREEN_BYTES];
    for r in 0..SCREEN_BYTES / bpl {
        for p in 0..planes {
            for k in 0..plane_line {
                let dst = r * bpl + (k / 2) * 2 * planes + p * 2 + (k & 1);
                out[dst] = linear[r * bpl + p * plane_line + k];
            }
        }
    }
    out
}
```

Sanity anchors (assert these in unit tests, §8.1-degas): low res
(`P=4, bpl=160, plane_line=40`) — linear byte (r=0, p=0, k=0..3) →
interleaved 0,1,8,9; (r=0, p=1, k=0..1) → interleaved 2,3; (r=0, p=3, k=38..39)
→ interleaved 158,159 (i.e. `(19/… )` word 19, plane 3). High res (`P=1`):
`reinterleave` is the identity.

**5.4.4 Render.**

```rust
fn render(bytes: &[u8]) -> Option<Vec<u8>> {
    let w = be16(bytes, 0)?;
    let res = ScreenRes::from_word(w & 0x7FFF)?;
    let words = palette_words(bytes.get(2..34)?)?;
    let pal = Palette::from_words(&words);
    let screen: Cow<[u8]> = if w & 0x8000 != 0 {
        let (linear, _) = rle_decode(bytes.get(34..)?)?;
        Cow::Owned(reinterleave(&linear, res))
    } else {
        Cow::Borrowed(bytes.get(34..34 + SCREEN_BYTES)?)
    };
    let img = warn_none("degas", decode_planar(&screen, res, &pal))?;
    warn_none("degas", png_bytes(&img))
}

        .ok()
```

### 5.5 `src/ripper/plugins/neochrome.rs` — NEW: NeoChrome .NEO

```rust
    )]

/// Render via the plugin that produced the finding, then materialize.
/// Ok(None) = plugin can't render these bytes (caller → invalid_params).

    finding: &Finding,
    out_dir: &std::path::Path,
    seq: u64,

        return Ok(None);
    };
    let ex = crate::ripper::extract_png(finding, &png, out_dir, seq)?;
    Ok(Some((ex, png)))
}
```

```rust
impl HatariServer {
    /// Lock the session once; gather screen bytes + effective res/palette.
    async fn grab_screen(
        &self,
        addr: Addr,
        res: Option<ScreenRes>,
        pal: Option<[u16; 16]>,
    ) -> Result<(crate::types::MemImage, ScreenRes, [u16; 16], std::path::PathBuf), McpError> {
        let mut guard = self.session.lock().await;
        let name = guard.state_name();
        let proc = guard
            .process_mut()
            .ok_or_else(|| wrong_state(name, "running or paused"))?;
        if addr.raw() as usize + SCREEN_BYTES > proc.config().ram_len() {
            return Err(McpError::invalid_params(
                format!("{addr} + 32000 exceeds ST RAM ({} bytes)", proc.config().ram_len()),
                None,
            ));
        }
        let work_dir = proc.config().work_dir.clone();
        let res = match res {
            Some(r) => r,
            None => live_res(proc).await?,
        };
        let words = match pal {
            Some(w) => w,
            None => live_palette(proc).await?,
        };
        let mem = memory::acquire_range(proc, addr, SCREEN_BYTES)
            .await
            .map_err(to_mcp)?;
        Ok((mem, res, words, work_dir))
    }
}
```

```rust
        .ok_or_else(|| McpError::internal_error("short palette-register read", None))
}

fn res_from_str(s: &str) -> Result<ScreenRes, McpError> {
    match s.to_ascii_lowercase().as_str() {
        "low" => Ok(ScreenRes::Low),
        "med" | "medium" => Ok(ScreenRes::Med),
        "high" => Ok(ScreenRes::High),
        _ => Err(McpError::invalid_params(
            format!("unknown res '{s}': use low|medium|high"),
            None,
        )),
    }
}

/// Exactly 16 entries; each "$0777" / "0x777" / decimal, ≤ 0xFFF enforced
/// by masking (upper nibble is unused hardware-side).
fn parse_palette_arg(v: Vec<String>) -> Result<[u16; 16], McpError> {
    if v.len() != 16 {
        return Err(McpError::invalid_params(
            format!("palette needs exactly 16 words, got {}", v.len()),
            None,
        ));
    }
    let mut out = [0u16; 16];
    for (o, s) in out.iter_mut().zip(&v) {
        *o = parse_word(s)? & 0x0FFF;
    }
    Ok(out)
}

fn parse_word(s: &str) -> Result<u16, McpError> {
    let bad = || McpError::invalid_params(format!("bad palette word {s:?}"), None);
    let (digits, radix) = match (s.strip_prefix('$'), s.strip_prefix("0x").or_else(|| s.strip_prefix("0X"))) {
        (Some(h), _) => (h, 16),
        (None, Some(h)) => (h, 16),
        _ => (s, 10),
    };
    u16::from_str_radix(digits, radix).map_err(|_| bad())
}
```

```markdown
## 2026-07-XX — ADR-12: Picture rendering via RipPlugin::render_png; extract returns CallToolResult

**Status:** accepted
**Context:** P4 adds picture decoding (Degas, NeoChrome). `extract as=png`
must decode a finding's planar bytes and hand the agent the picture inline
(PLAN §P4), which raises two design questions: where does per-format decode
live without breaking ADR-2's "add a format = one file + one registry line"
property, and how does a tool that previously returned typed JSON also carry
an image content block?
**Decision:** (1) `RipPlugin` gains a **defaulted** `render_png(&self, bytes)
-> Option<Vec<u8>>` — a picture plugin implements scan + render in its one
file; non-picture plugins inherit `None`. `Registry::render_png(plugin_id,
bytes)` is the engine-generic lookup; the tool layer resolves the finding's
producing plugin through it. `None` doubles as "corrupt input" (with a
tracing::warn), symmetric with `Depacker::try_unpack` — render never errors.
(2) The `extract` tool returns `CallToolResult`: raw/prg produce one text
block containing the serialized `ExtractOutput` JSON; png produces an
`image/png` block plus the same JSON text block. PNG stays out of
`ExtractFormat` (it is a render, not a byte container — tool-layer
`WireFormat` splits the pipelines). (3) Palette decoding auto-detects STE
per-palette (`any word & 0x0888 != 0`) and detection requires a plausible
palette (upper nibbles clear, ≥ 4 distinct words) — the distinctness gate is
what keeps zero-filled RAM from matching everywhere. (4) Graphics test
fixtures are generated by byte-pinned builders in `tests/graphics.rs`, not
committed binaries (archive images have unclear redistribution status; a
pinned builder is a better golden reference anyway).
**Alternatives considered:** a byte-sniffing `picture::decode(bytes)`
dispatcher (rejected: a second per-format registration point, eroding the
one-file property); a separate `Renderer` trait + registry role (rejected:
more machinery for zero extra capability — every renderer is a detector);
keeping `extract` as `Json<ExtractOutput>` and adding a separate
`extract_png` tool (rejected: fatter tool surface for one format flag,
against the progressive-disclosure grouping in ADR-5); `structured_content`
on `CallToolResult` (rejected: unverified construction path in rmcp 2.2, the
text-block JSON carries the same information).
**Consequences:** `extract` no longer advertises an outputSchema — its JSON
now travels inside a text block (agents parse it fine; handshake test
updated). A future picture format is still one file + one registry line,
including its PNG rendering. Corrupt-picture renders surface to the agent as
invalid_params ("not renderable"), with detail only in server logs. ST-vs-STE
palette ambiguity is resolved per-palette, so an all-ST-range STE image
decodes with ST scaling (imperceptible: ≤ 2/255 per channel).
```
