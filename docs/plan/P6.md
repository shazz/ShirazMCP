## 4. Normative formats (pinned)

### 4.1 SNDH blob layout

Authority: skill `atari-st-ym-players` §1 + `sndh.c` (above). All multi-byte
integers big-endian. `o` = header base offset in the scanned buffer.

```
o+0   4 bytes  entry slot 0: init   (d0 = subtune number on entry)
o+4   4 bytes  entry slot 1: exit / deinit
o+8   4 bytes  entry slot 2: play   (call once per VBL / timer tick)
o+12  4 bytes  ASCII magic "SNDH"
o+16  …        tag block: 4-char and 2-char ASCII tags with values
…     4 bytes  "HDNS" terminator; header padded to even length after it
then           replay code + song data (length NOT recorded anywhere)
```

**Entry slots.** Each 4-byte slot must decode as a 68k branch for the blob
to count as SNDH. Accepted encodings per slot (anything else = slot invalid):

| word at slot | form | target (relative to `o`) |
|---|---|---|
| `0x6000` | `bra.w`, displacement word follows | `slot*4 + 2 + (disp16 as i16)` |
| `0x60xx`, `xx ∉ {00, FF}` | `bra.s` (2 filler bytes ignored) | `slot*4 + 2 + (xx as i8)` |

A decoded target is **valid** iff `target >= 12`, `target` is even, and
`target < buffer_len - o`. Detection gate: slots 0 (init) and 2 (play) must
both be valid; slot 1 (exit) is optional (some rips stub it).

**Tag block.** Scanned by bounded substring search (the `sndh.c` approach —
tags are not sequentially parseable without knowing every tag's value
format). Region: `o+16 ..= min(o+16+TAG_SCAN_MAX, buffer_len)` with
`TAG_SCAN_MAX = 2048`. First find `"HDNS"` in the region; if found, the tag
search region shrinks to end there and
`header_len = round_up_even(16 + hdns_pos_in_region + 4)`; if not found,
`header_len = None` and tags are searched in the full 2048-byte window
(degraded, not an error).

Tags parsed (and ONLY these — `YEAR`, `TIME`, `!#`, `TYPE` etc. are out of
scope, §10):

| tag | value format | field |
|---|---|---|
| `TITL` | NUL-terminated ASCII | `title` |
| `COMM` | NUL-terminated ASCII | `composer` |
| `RIPP` | NUL-terminated ASCII | `ripper` |
| `CONV` | NUL-terminated ASCII | `converter` |
| `##` | ASCII decimal digits immediately after | `subtunes` (default **1**) |
| `TA`/`TB`/`TC`/`TD` | ASCII decimal digits immediately after (Hz) | `replay` + `freq_hz` |
| `!V` **or** `V!` | ASCII decimal digits immediately after (Hz) | `replay = Vbl` + `freq_hz` |

Timer priority when several match (authority `sndh.c`): **TC, TA, TB, TD,
!V, V!** — first in that order wins, regardless of position. Guard against
2-char tags matching inside title text (a real `sndh.c` bug): a `##`/timer
tag only counts if the byte immediately after it is an ASCII digit
`'0'..='9'`. Defaults when absent: `replay = Vbl`, `freq_hz = 50` (the
`sndh.c` default).

**Finding length.** The SNDH format records no total length; RAM has no file
end. Pinned heuristic: `len = min(SNDH_RIP_CAP, buffer_len - o)` with
`SNDH_RIP_CAP = 65536` (64 KiB — real SNDH players + data virtually always
fit; ADR-16 consequence). The scan advances past the 4-byte magic only
(`find_iter` semantics), so adjacent/overlapping blobs are still found.

### 4.2 YM write-loop anchor

Authority: skill `ym2149-psg` — every ST replay ultimately writes the PSG
through `$FFFF8800` (register select) / `$FFFF8802` (data). These are
**hardware constants**: relocation-invariant, unlike pointers into song
data. On the 68000 they appear in code as either the absolute-long operand
bytes `FF FF 88 00` / `FF FF 88 02`, or the absolute-short operand bytes
`88 00` / `88 02` (`$8800.w` sign-extends to `$FFFF8800`).

Two-phase detection (the load-bearing efficiency choice — do **not** linear-
disassemble the whole image; ADR-16 records the alternative and why it
loses):

1. **Byte candidates** (`memchr::memmem`): every even offset where one of
   the four byte patterns above occurs. A short-form candidate is suppressed
   when the two preceding bytes are `FF FF` (it is the tail of a long-form
   candidate already collected).
2. **Disasm confirmation:** an operand at offset `c` belongs to an
   instruction starting at `c - back` for `back ∈ {2, 4, 6}` (opcode word;
   opcode + immediate word; opcode + immediate long). For each `back` in
   that order, `disasm(mem, base + (c - back), 1)`; the candidate is
   **confirmed** iff the decoded instruction (a) has mnemonic starting with
   `"move"` or `"lea"` (covers `move.b/w/l`, `movea`, `lea.l`; `moveq`
   cannot reference memory so it is harmless), (b) its `ops` text contains
   one of the four PSG tokens `"$ffff8800"`, `"$ffff8802"`, `"$8800.w"`,
   `"$8802.w"` (P2 pinned Capstone conventions), and (c) its byte length is
   `> back` (the operand bytes belong to *this* instruction). First
   confirming `back` wins; no confirmation → the candidate was data, skip.
   Accepting `lea`/`movea` matters: many replays do `lea $ffff8800.w,a0`
   once and write via `(a0)` — the `lea` is the anchor we get.

3. **Clustering:** confirmed hits sorted by instruction offset, deduped,
   grouped while the next hit starts within `CLUSTER_GAP = 512` bytes of the
   current cluster's end. One `Finding` per cluster: `offset` = first hit's
   instruction offset, `len` = last hit's `offset + len` minus the first's.
   `replay_addr` is therefore `Finding::addr()` — the engine-attached bus
   address of the cluster start (or `None` for findings inside depacked
   buffers, which have no bus address; the wire layer already handles that).

Known accepted noise: OS/driver code in RAM that touches PSG port A (floppy
select via R14) can produce low-confidence clusters. Acceptable — findings
are kind=music, labelled, and cheap to ignore; MIN hits per cluster is 1.

### 4.3 Signature scheme (relocation-tolerant fingerprints)

A signature is a sequence of masked big-endian 16-bit words matched over raw
buffer bytes: word `j` at candidate position `i` matches iff
`(BE16(buf[i+2j..]) & mask[j]) == value[j]`. Masking rules:

- **Hardware constants** (`$FFFF8800`, register numbers, envelope-shape
  immediates) are literal: `mask = 0xFFFF`.
- **Relocated address operands** (pointers into song/code — different per
  rip/depack) are fully masked: `mask = 0x0000` (word matches anything).
- **Register fields** in an opcode word are masked out where the register
  choice varies (e.g. `move.b dN,…` → `value 0x13C0, mask 0xFFF8`).

Two scopes:

- `AnchorWindow` — code fingerprints, searched at even offsets in
  `[cluster_start - 512, cluster_end + 512]` (clamped to the buffer,
  `WINDOW = 512`).
- `WholeImage` — data magics (module-format ASCII ids), searched at **every**
  byte offset of the buffer. Caveat (ADR-16 consequence, documented in the
  module doc): a WholeImage match names *every* cluster in the image; with
  two different players resident simultaneously this can mislabel — rare in
  practice, accepted for v1.

Best match = highest `confidence`; tie → first in DB order. **No match →
`("unknown", CONF_ANCHOR_ONLY = 0.25)` — never an error, never a panic**
(the mandated graceful degradation).

**Seed DB (const data, §5.5).** Provenance honesty, pinned: the four seed
entries below are **provisional** — derived from documented format magics
and documented player behavior (skill §3), NOT yet extracted from the
labelled SNDH corpus (`frno7/sndhfix` / sndh.atari.org) as the skill
ultimately requires. Each carries a calibrated-down confidence and a
`// verify live` marker; refining them against the corpus is backlog
(ADR-16). The matcher itself is fully proven by tests (§8.4) independent of
entry provenance, and a wrong/missing signature can only ever produce
`"unknown"` — the degradation contract makes provisional data safe to ship.

| id (comment) | player string | scope | pattern (value/mask hex words) | conf |
|---|---|---|---|---|
| hippel-code | `Jochen Hippel (Mad Max)` | AnchorWindow | `13FC/FFFF 000D/FFFF FFFF/FFFF 8800/FFFF 13C0/FFF8 FFFF/FFFF 8802/FFFF` — `move.b #$0d,$ffff8800.l` (select R13, envelope shape — the SID-voice/sync-buzzer tell) + `move.b dN,$ffff8802.l` with the data register masked | 0.70 |

```rust
/// How the tune expects to be driven (SNDH timer tags).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Replay { TimerA, TimerB, TimerC, TimerD, Vbl }

impl Replay {
    pub const fn as_str(self) -> &'static str {
        // "timer-a" | "timer-b" | "timer-c" | "timer-d" | "vbl"
    }
}

/// Parsed SNDH header facts. Offsets are relative to the header base.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SndhInfo {
    pub title: Option<String>,
    pub composer: Option<String>,
    pub ripper: Option<String>,
    pub converter: Option<String>,
    pub subtunes: u16,          // default 1
    pub replay: Replay,         // default Vbl
    pub freq_hz: u16,           // default 50
    pub init: u32,              // entry offsets; validation guarantees init/play
    pub exit: Option<u32>,
    pub play: u32,
    pub header_len: Option<usize>, // Some iff HDNS found (padded even)
}

/// Parse an SNDH header whose magic sits at `o + 12`. None = not SNDH
/// (bad magic, invalid init/play branches) — never a panic.
pub fn parse_header(bytes: &[u8], o: usize) -> Option<SndhInfo>
```

Implementation (exact):

1. `bytes.get(o + 12..o + 16)? == b"SNDH"` else `None`.
2. `let init = entry_offset(bytes, o, 0)?; let play = entry_offset(bytes, o, 2)?;`
   `let exit = entry_offset(bytes, o, 1);` — init/play required, exit
   optional (§4.1).
3. Tag region: `let end = (o + 16 + TAG_SCAN_MAX).min(bytes.len());`
   `let region = &bytes[o + 16..end];` (empty region is fine).
4. `HDNS`: `let hdns = memmem::find(region, b"HDNS");`
   `let tags = &region[..hdns.unwrap_or(region.len())];`
   `let header_len = hdns.map(|p| { let l = 16 + p + 4; l + (l & 1) });`
5. Strings: `title/composer/ripper/converter = cstr_tag(tags, b"TITL"| b"COMM" | b"RIPP" | b"CONV")`.
6. `subtunes = digit_tag(tags, b"##").unwrap_or(1)`.
7. Timer, first hit in pinned priority order (§4.1):
   ```rust
   const TIMERS: [(&[u8], Replay); 6] = [
       (b"TC", Replay::TimerC), (b"TA", Replay::TimerA),
       (b"TB", Replay::TimerB), (b"TD", Replay::TimerD),
       (b"!V", Replay::Vbl),    (b"V!", Replay::Vbl),   // sndh.c spells it "V!"
   ];
   ```
   `(replay, freq_hz)` from the first `(tag, r)` where `digit_tag(tags, tag)`
   is `Some(f)` → `(r, f)`; else `(Replay::Vbl, 50)`.

Helpers (each ≤ 20 lines, all private except `parse_header`):

```rust
/// Decode entry slot `slot` (0=init, 1=exit, 2=play) per §4.1.
/// None = slot word is not bra.w/bra.s, or target invalid.
fn entry_offset(bytes: &[u8], o: usize, slot: usize) -> Option<u32> {
    let w = be16(bytes, o + slot * 4)?;
    let t: i32 = if w == 0x6000 {
        slot as i32 * 4 + 2 + i32::from(be16(bytes, o + slot * 4 + 2)? as i16)
    } else if w >> 8 == 0x60 && !matches!(w & 0xFF, 0x00 | 0xFF) {
        slot as i32 * 4 + 2 + i32::from((w & 0xFF) as u8 as i8)
    } else {
        return None;
    };
    (t >= 12 && t % 2 == 0 && (t as usize) < bytes.len() - o).then_some(t as u32)
}

fn be16(bytes: &[u8], o: usize) -> Option<u16>  // as in neochrome.rs

/// First `tag` occurrence in the tag block → the NUL-terminated string after.
fn cstr_tag(tags: &[u8], tag: &[u8]) -> Option<String> {
    let p = memmem::find(tags, tag)?;
    read_cstr(&tags[p + tag.len()..])
}

/// First `tag` occurrence followed by an ASCII digit → parsed decimal.
/// The digit gate stops timer tags matching inside title text (§4.1).
fn digit_tag(tags: &[u8], tag: &[u8]) -> Option<u16> {
    memmem::find_iter(tags, tag)
        .find(|&p| tags.get(p + tag.len()).is_some_and(u8::is_ascii_digit))
        .map(|p| parse_decimal(&tags[p + tag.len()..]))
}

/// Leading ASCII digits, decimal, saturating at u16::MAX.
fn parse_decimal(bytes: &[u8]) -> u16 {
    bytes.iter().take_while(|b| b.is_ascii_digit()).take(5)
        .fold(0u16, |v, b| v.saturating_mul(10).saturating_add(u16::from(b - b'0')))
}

/// ASCII value up to the NUL; NUL must appear within 128 bytes (garbage
/// guard) and the value must be non-empty. Non-printables become '?'.
fn read_cstr(bytes: &[u8]) -> Option<String> {
    let window = &bytes[..bytes.len().min(128)];
    let end = window.iter().position(|&b| b == 0)?;
    (end > 0).then(|| {
        window[..end].iter()
            .map(|&b| if (0x20..=0x7E).contains(&b) { b as char } else { '?' })
            .collect()
    })
}
```

`digit_tag` note: `u8::is_ascii_digit` needs the by-ref call shape
(`is_some_and(u8::is_ascii_digit)` on a `&u8` — adjust to a closure if
clippy objects; behavior is the contract, not the call style).

### 5.3 `src/ripper/plugins/sndh.rs`

Module doc: "SNDH detector (§4.1). Finds `SNDH` blobs anywhere in a buffer;
header facts parsed by `sndh_header`. Length is the pinned 64 KiB cap
heuristic (ADR-16) — the format records no total length."

```rust
use memchr::memmem;

use crate::ripper::plugins::sndh_header::{parse_header, SndhInfo};
use crate::ripper::{Finding, RipKind, RipPlugin};
use crate::types::{MemImage, Offset, PluginId};

/// SNDH records no total length; rip a capped window (§4.1, ADR-16).
pub const SNDH_RIP_CAP: usize = 65536;

pub struct Sndh;

impl RipPlugin for Sndh {
    fn id(&self) -> PluginId { PluginId::new("sndh") }
    fn kind(&self) -> RipKind { RipKind::Music }
    fn describe(&self) -> &'static str {
        "SNDH music blobs (init/exit/play entries + TITL/COMM/RIPP/subtune/timer tags)"
    }
    fn scan(&self, mem: &MemImage) -> Vec<Finding> {
        let bytes = mem.bytes();
        memmem::find_iter(bytes, b"SNDH")
            .filter_map(|m| m.checked_sub(12))
            .filter_map(|o| {
                let info = parse_header(bytes, o)?;
                let len = (bytes.len() - o).min(SNDH_RIP_CAP);
                Some(Finding::new(self.id(), RipKind::Music, Offset::new(o), len, label(&info)))
            })
            .collect()
    }
```

### 5.4 `src/ripper/plugins/ym_player.rs`

Module doc: "YM2149 replay locator (§4.2, ADR-16): byte candidates for the
`$FFFF8800`/`$FFFF8802` operands, confirmed by one-instruction Capstone
decodes (P2 `analyze::disasm`), clustered, then named via `ym_signatures`.
The label carries `player`/`confidence`/`hits` in a pinned machine-parseable
format (`format_label`/`parse_label` round-trip) — the channel
`tools/music.rs` reads structured results back through."

```rust
use memchr::memmem;

use crate::analyze::disasm::disasm;
use crate::ripper::plugins::ym_signatures;
use crate::ripper::{Finding, RipKind, RipPlugin};
use crate::types::{Addr, MemImage, Offset, PluginId};

/// Confirmed hits this close (bytes) merge into one replay cluster.
pub const CLUSTER_GAP: usize = 512;
/// Instruction starts to try behind an operand: opcode | +imm.w | +imm.l.
const BACKS: [usize; 3] = [2, 4, 6];

#[derive(Debug, Clone, Copy)]
struct Hit { off: usize, len: usize }

#[derive(Debug, Clone, Copy)]
struct Cluster { start: usize, end: usize, hits: usize }

pub struct YmPlayer;

impl RipPlugin for YmPlayer {
    fn id(&self) -> PluginId { PluginId::new("ym-player") }
    fn kind(&self) -> RipKind { RipKind::Music }
    fn describe(&self) -> &'static str {
        "YM2149 replay routines ($FFFF8800/$FFFF8802 write anchor + player fingerprint)"
    }
    fn scan(&self, mem: &MemImage) -> Vec<Finding> {
        let hits: Vec<Hit> = find_candidates(mem.bytes())
            .into_iter()
            .filter_map(|c| confirm(mem, c))
            .collect();
        clusters(hits)
            .into_iter()
            .map(|c| {
                let id = ym_signatures::identify(mem.bytes(), c.start, c.end);
                Finding::new(
                    self.id(), RipKind::Music, Offset::new(c.start), c.end - c.start,
                    format_label(id.player, id.confidence, c.hits),
                )
            })
            .collect()
    }
}
```

Free functions (exact):

```rust
/// Even offsets of PSG operand byte patterns (§4.2 step 1). Short-form hits
/// preceded by FF FF are the tail of a long-form hit — suppressed.
fn find_candidates(bytes: &[u8]) -> Vec<usize> {
    let mut out = Vec::new();
    for pat in [&[0xFF, 0xFF, 0x88, 0x00][..], &[0xFF, 0xFF, 0x88, 0x02]] {
        out.extend(memmem::find_iter(bytes, pat).filter(|i| i % 2 == 0));
    }
    for pat in [&[0x88, 0x00][..], &[0x88, 0x02]] {
        out.extend(memmem::find_iter(bytes, pat).filter(|&i| {
            i % 2 == 0 && !(i >= 2 && bytes[i - 2..i] == [0xFF, 0xFF])
        }));
    }
    out.sort_unstable();
    out.dedup();
    out
}

/// §4.2 step 2: try instruction starts at cand-2/-4/-6; accept the first
/// single-insn decode that is a move/lea whose text references the PSG and
/// whose bytes cover the operand. None = data, not code.
fn confirm(mem: &MemImage, cand: usize) -> Option<Hit> {
    for back in BACKS {
        let Some(off) = cand.checked_sub(back) else { continue };
        let at = Addr::new(mem.base().raw() + off as u32);
        let Ok(insns) = disasm(mem, at, 1) else { continue };
        let Some(i) = insns.first() else { continue };
        if (i.mnemonic.starts_with("move") || i.mnemonic.starts_with("lea"))
            && is_psg(&i.ops)
            && i.bytes.len() > back
        {
            return Some(Hit { off, len: i.bytes.len() });
        }
    }
    None
}

/// P2-pinned Capstone spellings of the two PSG ports (long + short forms).
/// // verify live: re-pin against P2.md §6.2 table on any capstone bump.
fn is_psg(ops: &str) -> bool {
    ["$ffff8800", "$ffff8802", "$8800.w", "$8802.w"]
        .iter().any(|t| ops.contains(t))
}

/// §4.2 step 3. Input order arbitrary; output sorted by start.
fn clusters(mut hits: Vec<Hit>) -> Vec<Cluster> {
    hits.sort_unstable_by_key(|h| h.off);
    hits.dedup_by_key(|h| h.off);
    let mut out: Vec<Cluster> = Vec::new();
    for h in hits {
        match out.last_mut() {
            Some(c) if h.off <= c.end + CLUSTER_GAP => {
                c.end = c.end.max(h.off + h.len);
                c.hits += 1;
            }
            _ => out.push(Cluster { start: h.off, end: h.off + h.len, hits: 1 }),
        }
    }
    out
}

/// The pinned label wire-format. `player` is bracketed so names with spaces
/// and parentheses survive; confidence prints 2 decimals (DB constants are
/// 2-decimal literals, §4.3, so the round-trip is exact).
pub fn format_label(player: &str, confidence: f32, hits: usize) -> String {
    format!("YM replay [{player}] confidence={confidence:.2} hits={hits}")
}

/// Inverse of `format_label`. None = not a ym-player label (defensive; the
/// tool treats that as no identification, §6.2).
pub fn parse_label(label: &str) -> Option<(String, f32, u32)> {
    let rest = label.strip_prefix("YM replay [")?;
    let close = rest.rfind("] confidence=")?;
    let tail = &rest[close + "] confidence=".len()..];
    let (conf, hits) = tail.split_once(" hits=")?;
    Some((rest[..close].to_string(), conf.parse().ok()?, hits.parse().ok()?))
}
```

```rust
    pub scope: SigScope,
    pub confidence: f32,

pub const WINDOW: usize = 512;

    Signature { player: "Jochen Hippel (Mad Max)", scope: SigScope::WholeImage, confidence: 0.65,
        pattern: &[w(0x5446, 0xFFFF), w(0x4D58, 0xFFFF)] },
    Signature { player: "maxYMiser", scope: SigScope::WholeImage, confidence: 0.60,
        pattern: &[w(0x6D61, 0xFFFF), w(0x7859, 0xFFFF), w(0x4D69, 0xFFFF), w(0x7365, 0xFFFF)] },
    Signature { player: "Lucas/Quartet", scope: SigScope::WholeImage, confidence: 0.55,
        pattern: &[w(0x5155, 0xFFFF), w(0x4152, 0xFFFF), w(0x5445, 0xFFFF), w(0x5400, 0xFF00)] },
];

/// Name the player behind an anchor cluster. Best = highest confidence,
/// tie → first in DB order; nothing matched → ("unknown", 0.25).
pub fn identify(buf: &[u8], cluster_start: usize, cluster_end: usize) -> PlayerId {
    let mut best: Option<&Signature> = None;
    for sig in SIGNATURES {
        let (lo, hi, step) = match sig.scope {
            SigScope::AnchorWindow => (
                cluster_start.saturating_sub(WINDOW) & !1,
                (cluster_end + WINDOW).min(buf.len()),
                2,
            ),
            SigScope::WholeImage => (0, buf.len(), 1),
        };
        if match_in(buf, lo, hi, sig.pattern, step)
            && best.is_none_or(|b| sig.confidence > b.confidence)
        {
            best = Some(sig);
        }
    }
    best.map_or(
        PlayerId { player: "unknown", confidence: CONF_ANCHOR_ONLY },
        |s| PlayerId { player: s.player, confidence: s.confidence },
    )
}

/// Any pattern start in [lo, hi) (stepped); the pattern may extend past hi
/// but must fit the buffer.
fn match_in(buf: &[u8], lo: usize, hi: usize, pat: &[SigWord], step: usize) -> bool {
    (lo..hi).step_by(step).any(|i| matches_at(buf, i, pat))
}

fn matches_at(buf: &[u8], i: usize, pat: &[SigWord]) -> bool {
    if i + 2 * pat.len() > buf.len() {
        return false;
    }
    pat.iter().enumerate().all(|(j, sw)| {
        let word = u16::from_be_bytes([buf[i + 2 * j], buf[i + 2 * j + 1]]);
        word & sw.mask == sw.value
    })
}
```

```rust
/// Err = store missing/raced (tool maps to internal_error).
pub(crate) fn music_summary(
    store: &Option<ScanStore>,
    scan_id: u64,
) -> Result<IdentifyMusicOutput, String> {
    let s = store.as_ref().ok_or("scan store empty after rip; retry")?;
    if s.scan_id != scan_id {
```

## 12. ADR-16 — append to `decisions.md` (verbatim; fill only the date)

```markdown
## 2026-07-XX — ADR-16: Music identification — disasm-confirmed YM anchor, provisional masked-word signature DB, label round-trip channel

**Status:** accepted
**Context:** P6 must name the music driver resident in RAM. SNDH blobs are
self-describing (header tags), but raw ripped/depacked players are not; the
only relocation-invariant trace of any driver is code referencing the PSG
ports `$FFFF8800`/`$FFFF8802` (ym2149-psg skill). Fingerprinting needs code
context; findings need to reach the `identify_music` tool in structured form
without changing the engine.
**Decision:** (1) Anchor = two-phase scan: memmem byte candidates for the
four operand encodings (abs.l / abs.w × select / data port), each confirmed
by a single-instruction Capstone decode at candidate−{2,4,6} (P2
`analyze::disasm`) gated on move/lea mnemonics + the P2-pinned PSG operand
text; confirmed hits cluster within 512 bytes into one Finding per replay
routine. This introduces the (pinned-legal) `ripper → analyze` dependency —
`analyze` is a pure leaf over `types`. (2) Naming = const signature DB of
masked big-endian words: hardware constants literal, relocated address
operands mask 0x0000, opcode register fields partially masked; scopes
AnchorWindow (code, ±512) and WholeImage (format magics). Seeds for
Hippel/Mad Max, TCB Tracker, maxYMiser, Lucas/Quartet are PROVISIONAL
(documented magics + documented envelope-shape behavior, not yet
corpus-extracted); no match degrades to ("unknown", 0.25) — never an error.
(3) The ym-player Finding label is a pinned machine-parseable format
(`format_label`/`parse_label`, round-trip tested); `identify_music` rebuilds
structure from it plus a re-parse of SNDH finding bytes, instead of
extending `Finding` with a metadata field. (4) SNDH finding length is a
64 KiB cap heuristic — the format records no total length.
**Alternatives considered:** Linear-disassembling the whole image (2M
decodes on 4 MB, stream-alignment garbage; rejected). A typed
`Finding.metadata` field (engine + wire change for one plugin; revisit if a
third plugin needs structured labels). Shipping corpus-extracted
fingerprints now (needs a labelled SNDH corpus pass; deferred to backlog —
the degradation contract makes provisional data safe). Naming players from
the SNDH `CONV` tag (surfaced raw instead; fusing it into confidence is
backlog).
**Consequences:** Unknown drivers are a first-class, non-error outcome.
Provisional signatures may misname exotic rips at their stated ≤0.80
confidence; WholeImage magics label every anchor in an image (mislabels
multi-player images — rare, accepted). OS floppy-select code (PSG port A)
can surface as low-confidence anchors. The 64 KiB SNDH cap can truncate
pathological blobs or over-grab trailing RAM. Signature refinement against
frno7/sndhfix + the sndh.atari.org corpus is the pinned improvement path.
```
